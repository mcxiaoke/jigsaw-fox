## [2026-08-25 15:32 GMT+8] 修复拼图界面横屏状态条遮挡棋盘 & 托盘碎片未打乱两大问题

### 变更内容
1. **修复横屏时顶部计时/进度状态条遮挡拼图区域 (`lib/pages/game_page.dart`)**：
   - 原实现中 Flame 游戏画布以 `Positioned.fill` 铺满全屏，而引擎内部仅预留固定 `_topToolbarHeight = 52.0` 的顶部空间，实际 Flutter 头部（AppBar 48 + 状态子栏 + 进度条）约 100px，导致横屏下棋盘被压在头部之下；
   - 重构为 `Column(头部 + Expanded(GameWidget))` 结构：头部（导航栏、计时/进度工具栏、细进度条）与游戏画布纵向排布、互不重叠，任意方向均不再遮挡；

2. **修复托盘碎片顺序未打乱、可直接按序拼成原图 (`lib/game/jigsaw_puzzle_game.dart`)**：
   - 根因：初始化按 `id = r*cols+c` 顺序将碎片依次放入托盘，且 `_realignTrayPieces` 也按 id 插入顺序重排，导致托盘排列与原图完全一致；
   - 新增 `_trayOrder` 字段：`onLoad` 时用 `Random(seed)` 对全部碎片 id 洗牌后决定托盘从左到右的摆放顺序；
   - `resetCurrentGame()` 重开本局时用新的随机种子重新洗牌，保证每次重置排列都不同；
   - `_realignTrayPieces()` / 托盘滚动等重排逻辑改为严格遵循 `_trayOrder` 顺序。
3. **Flame 内部顶部预留高度** `_topToolbarHeight` 由 52.0 调整为 8.0（画布已位于头部下方，仅需保留少量上边距）。
