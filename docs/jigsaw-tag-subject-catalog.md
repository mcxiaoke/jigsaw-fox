# 拼图 20 类标签主体元素百科与生图指南

> **用途**：为 Z-Image / ComfyUI 等文生图模型提供每个 Tag 下主流主体元素参考词表、环境搭档与 Prompt 关键词。
> **依据**：`jigsaw-image-tagging-specification.md` v1.1 的 20 个固定 Tag，综合图库分类、摄影分类及奇幻生物、美食摄影等专题资料整理。

---

## 0. 拼图生图核心原则

拼图的乐趣与难度来源于**碎片边缘的局部可辨识性**。一张适合做拼图的优质图片必须满足：

1. **色彩高熵**：画面全局色彩丰富、饱和且多梯度，禁止整张图偏向单一色相。
2. **明确视觉锚点**：画面中存在易识别的核心主体，作为玩家起手拼装的定位基准。
3. **高密度微表面纹理**：毛发、鳞片、羽毛、石缝、木纹、水珠等微观细节遍布全画幅。
4. **零死区分区构图**：禁止大面积死黑/死白、大片无云纯蓝天、棚拍纯色虚化背景。

> **修订说明（2026-09-01）**：原环境搭档为「编织毛线团、藤编猫窝、彩色咬胶玩具、格子软垫、壁炉木地板」等**桌面级小物件**。
> v5 的 `animal` 模板组会强制把 env 塞进 `{env_bg} in the distance / on the horizon` 远景槽位，
> 实测产出过 `colorful chew toys on the horizon`（彩色咬胶玩具出现在地平线上）这类荒谬构图，
> 且小物件撑不满 1:1 画幅 → 大面积留白。JigsawTest2 中 Pets 均分 47.4、F 级淘汰率 33%，为 20 个 tag 最差。
> 现统一改为**空间级环境**（房间/庭院/店铺），可同时承担前景-中景-背景三层，
> 并将 Pets 的模板组由 `animal` 调整为 `object`（后者无远景槽位）。

### Tag 03: Nature（自然生态与植物）

- **适玩**：B 级 | 比例 1:1, 2:3, 3:2
- **核心规避**：严禁大面积单一色块树冠或空旷平原；强化中近景植物结构与光影分层。

**主体元素：**

- **古树与林木**：千年红杉、银杏古树、大榕树气生根、翠绿竹林、白桦林、蓝花楹树、参天古树、盘根错节
- **附生与微观植物**：苔藓、鸟巢蕨、地衣、卷柏、积水凤梨、多肉微型花园（石莲花、生石花、玉露）、仙人掌群落（金琥、巨柱）、食虫植物（捕蝇草、猪笼草）、盆景
- **真菌与微观奇境**：荧光蘑菇、红伞白斑毒蝇伞、羊肚菌、鸡油菌、灵芝、晨露叶脉水珠
- **自然水文与地质**：溪流跳石、苔藓瀑布、红树林呼吸根、喀斯特溶洞钟乳石、蓝冰微洞、霜花冰晶
- **时令地表**：松果橡子散落、野生浆果丛（覆盆子、蓝莓、黑莓）、层叠落叶地表
- **自然生态场景**：热带雨林内部、雾林、沼泽湿地、草原、沙漠绿洲、峡谷内部、天坑、红叶树林/槭树林
- **自然纹理**：树皮纹理、叶脉、岩石表面、河床、沙地纹理、冰晶、露珠

**环境搭档**：林间丁达尔光束、溪流飞溅水珠、深色朽木与鲜亮苔藓明暗对比。

**Prompt**：`glowing bioluminescent mushrooms on a mossy fallen log in primeval forest`, `lush succulent garden with diverse textures`, `dappled sunbeams`

- **田园与大地纹理**：元阳梯田、龙脊梯田、普罗旺斯薰衣草田、荷兰郁金香花田、托斯卡纳麦田山丘、喀纳斯月亮湾彩林、茶园、葡萄园、稻田、牧场

- **时段光影**：日出日落全景、黄金时刻山脉、星空银河地景、极光全景与湖泊倒影、云海雾海、朝霞晚霞

- **标志性场景**：国家公园标志景观（优胜美地半穹顶、黄石、大峡谷）、孤树地平线（非洲金合欢孤树、苏格兰孤树）、荷兰风车田野、覆盖桥（新英格兰风格）、开阔田野热气球群

**环境搭档**：前景野花花丛、风化岩石缝、木质围栏、倒影水洼、枯木倒影。

**Prompt**：`panoramic cascading rice terraces with reflective water at sunset`, `Matterhorn peak over alpine lake with wildflowers`, `layered foreground`

## 2. Z-Image / ComfyUI 提示词万能拼装公式

生产上述 20 类素材时，使用以下模块化结构组合 Prompt：

```text
[主体描述 + 明确姿态/动作] +
[高可玩性环境/道具锚点 + 材质微表面细节] +
[题材专属镜头参数] +
[光影氛围] +
[视角与构图] +
[色彩调色板] +
quality_suffix
```

### 推荐质量后缀

```text
highly detailed, intricate detail across the entire frame, dense visual texture,
rich and varied color palette, busy composition, filled frame with corner-to-corner
detail, deep depth of field, consistent sharpness, no excessive sky or water,
no repetitive micro textures
```

## 3. 使用说明

1. **选词方式**：从对应 Tag 下选择主体元素作为生图关键词，配合环境搭档与质量后缀组合使用。
2. **边界规则**：主体跨两个 Tag 时按 `jigsaw-image-tagging-specification.md` 优先级判定——题材优先于表现形式。卡通龙 → Fantasy，卡通猫 → Cartoon 或 Pets。
3. **护栏类标签**（Art / Seasons / Holidays / Abstract / Cartoon）：须确保图中有对应内容证据（绘画笔触、季节特征、节日符号、纯几何图案、卡通笔触），不能仅凭色调或氛围判定。
4. **C 级高危标签**（Ocean / Space / Abstract）：这三类极易生成大面积纯色死区，生图时必须强制注入高密度细节填充全画幅。
