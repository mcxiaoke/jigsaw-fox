## 一、 实体拼图纸板的核心物理特征分析

在现实世界中，实体拼图之所以具有强烈的“硬质纸板感”而非“数码贴纸感”，源于制造工艺（金属刀模冲压）与物理环境（定向光照与重力）下的 4 大核心特征：

```text
            光源 (左上方 135° 光照)
               ↘  ↘  ↘
         ┌───【迎光面高光微边 0.8px 半透明纯白】───┐
         │                                         │
         │              碎片正面图案               │
         │                                         │
         └───【背光面冲压暗线 1.2px 半透明深黑】───┘
               ↓↓【纸板物理厚度截面 1.5px~2.0px 浅灰/蓝卡夹芯】↓↓
               ░░【双层接触/悬浮阴影 Contact & Ambient Shadow】░░
```

### 1.1 冲压刀模挤压倒角（Bevel & Emboss）
- **物理成因**：实体拼图由金属冲压刀模自上而下挤压切断。切口不是 90° 锋利垂面，而是带有轻微的下陷挤压斜角（V-Groove）；
- **光学表现**：在斜上方（135°，即左上角）的主光源下：
  - **Top 边 & Left 边（迎光面）**：反射出极细的微弧度柔白高光线；
  - **Bottom 边 & Right 边（背光面）**：形成刀模凹陷造成的深色切缝阴影。

### 1.2 纸板物理厚度（3D Extrusion Side / 蓝卡夹芯）
- **物理成因**：高品质实体拼图通常选用 1.8mm ~ 2.2mm 的高密度蓝卡纸（Blueboard）或灰卡纸；
- **光学表现**：当碎片被拿起、悬浮在棋盘上方或堆叠时，在背光侧（右下方）会露出硬纸板的侧截面色（浅灰卡纸色 `Color(0xFFD6D0C4)`），增强纸板重量感。

### 1.3 分层物理投影（Contact Shadow vs. Float Shadow）
- **贴地状态（Contact AO）**：平铺在托盘或桌面上时，紧贴底板产生一圈紧致、极小模糊半径的接触微阴影，呈现纸板受重力压实的效果；
- **悬浮状态（Float Elevation）**：手指/鼠标拾起碎片时，碎片距离底板抬升，阴影呈现深层、大模糊半径的向右下方扩散的柔和投影。

### 1.4 亚麻/纸质漫反射微纹理（Linen Finish & Diffuse Noise）
- **物理成因**：高端实体拼图（如德国 Ravensburger / 经典 Jigsaw Explorer 艺术拼图）表面覆有一层压纹亚麻布纹膜（Linen Emboss Finish），由微细的十字交叉纤维凹凸光影构成；
- **光学表现**：
  - 打散直射强光，形成均匀柔和的漫反射（消除数码屏幕图片的纯平塑料反光感）；
  - 赋予画面细腻触感与高级艺术品印刷纸张特有的哑光质感。
- **程序化生成与 GPU 硬件采样**：
  - 采用 64x64 无缝平铺程序化生成的亚麻网格微纹理（带经纬编织丝线与微弱纸浆高斯微粒）；
  - 结合 `ImageShader` 的 `TileMode.repeated` 硬件纹理采样器，以 `BlendMode.softLight`（或约 4%~6% 极低透明度）混合覆盖在正面图案上，0 额外网络与包体负担，60fps/120fps 满帧运行。

## 二、 4 大方案分层渲染流水线 (Render Pipeline)

Canvas 自底向上的分层绘制管线如下：

| 层级 | 渲染阶段 | 触发条件 | 技术实现 | 视觉目的 |
| :--- | :--- | :--- | :--- | :--- |
| **Layer 1** | **物理投影层** | 全状态 | 静止：`offset(0, 0.8), blur 1.0`<br>拖拽：`offset(2.0, 6.0), blur 7.0` | 建立与桌面/托盘的空间高度与重力关系 |
| **Layer 2** | **纸板厚度截面层** | 拾起/拖拽悬浮状态 | `offset(0.8, 1.6)` 填充 `Color(0xFFD6D0C4)` 纸板夹芯色 + 描边 | 呈现 1.8mm 硬纸板三维体积感 |
| **Layer 3** | **正面图案纹理层** | 全状态 | `canvas.clipPath(shape.path)` + `drawImageRect` | 1:1 还原无失真高清图案采样 |
| **Layer 4** | **亚麻纸质漫反射层** | 纹理已就绪 | `canvas.drawRect(shape.fillRect, linenPaint)` (`softLight`/Overlay) | 消除数码塑料反光，呈现亚麻布纹纸质 |
| **Layer 5** | **迎光面高光微边** | 正常未高亮 | 沿 `shape.highlightPath` 绘制 `0.8px Color(0x45FFFFFF)` | 模拟左上方 135° 迎光面刀模斜角反光 |
| **Layer 6** | **背光面冲压暗线** | 正常未高亮 | 沿 `shape.shadowPath` 绘制 `1.2px Color(0x70000000)` | 模拟右下方背光面深陷切口阴影 |
| **Overlay** | **吸附成功光效** | 吸附触发 | 沿 `shape.path` 绘制 `2.5px Color(0xFF4CAF50)` 绿光 | 明确的拼装成功反馈 |

## 三、 几何切片定向路径拆分设计

为了实现方案 1 的迎光/背光精准分向着色，同时保持 100% 紧密咬合与极高绘制性能，`PieceShape` 内部将 12 点贝塞尔路径拆分为三组缓存：

```dart
class PieceShape {
  /// 1. 完整封闭轮廓：用于 clipPath、厚度层填充以及碰撞拾取
  late final Path path;

  /// 2. 迎光面路径 (Highlight Path)：
  ///    由 Top 边 (0,0 -> width,0) 与 Left 边 (0,height -> 0,0) 组合而成，在 (0,0) 顶点平滑交汇
  late final Path highlightPath;

  /// 3. 背光面路径 (Shadow Path)：
  ///    由 Right 边 (width,0 -> width,height) 与 Bottom 边 (width,height -> 0,height) 组合而成，在 (width,height) 顶点平滑交汇
  late final Path shadowPath;
}
```

### 3.1 路径方向与法向连续性
- **Top 边**：起点 `(0, 0)` $\to$ 终点 `(width, 0)`，外法线指向正上方 `(0, -1)`；
- **Left 边**：标准定义从 `(0, 0)` 到 `(0, height)`，在构建高光路径时以逆向 `(0, height) \to (0, 0)` 接入，使高光路径在 `(0, 0)` 处自然连续；
- **Right 边**：起点 `(width, 0)` $\to$ 终点 `(width, height)`，外法线指向正右方 `(1, 0)`；
- **Bottom 边**：标准定义从 `(0, height)` 到 `(width, height)`，在构建背光路径时以逆向 `(width, height) \to (0, height)` 接入，使背光路径在 `(width, height)` 处自然连续。

## 四、 核心物理参数规范

| 参数项 | 取值 | 说明 |
| :--- | :--- | :--- |
| **迎光高光线宽** | `0.8 px` | 纤细自然，避免过粗产生“儿童卡通白描边” |
| **迎光高光颜色** | `Color(0x45FFFFFF)` | 约 27% 不透明度半透明纯白，柔和反光 |
| **背光暗线线宽** | `1.2 px` | 形成微下陷挤压深度 |
| **背光暗线颜色** | `Color(0x70000000)` | 约 44% 不透明度半透明深黑，咬合线分明 |
| **纸板厚度偏移** | `Offset(0.8, 1.6)` | 对应 135° 光照投射出的背光侧厚度 |
| **纸板夹芯色** | `Color(0xFFD6D0C4)` | 真实高密度荷兰白卡/灰卡纸侧边天然色调 |
| **纸板底边暗线** | `0.8 px Color(0x55000000)` | 纸板厚度底部的接触边缘切线 |
| **静止接触阴影** | `Offset(0.0, 0.8), Blur 1.0, Color(0x30000000)` | 紧贴桌面的紧致环境光遮挡（AO） |
| **拖拽悬浮阴影** | `Offset(2.0, 6.0), Blur 7.0, Color(0x40000000)` | 拾起抬升时的深层柔和扩散阴影 |
| **亚麻微纹理尺寸** | `64 x 64 px` 无缝平铺 | 4px 周期经纬纤维织网 + 纸浆微粒 |
| **亚麻混合模式** | `BlendMode.softLight` / `0x0C` 透明度 | 柔和融于原图色彩，增强哑光纸质质感 |

## 五、 性能与兼容性评估

1. **GPU 矢量与采样器硬件加速**：
   - 几何路径（`path`, `highlightPath`, `shadowPath`）在尺寸变更时仅计算缓存一次；
   - 亚麻布纹使用 GPU 硬件 `TileMode.repeated` 采样器，0 循环计算，渲染单块仅多一次极速绘制；
2. **0 额外离屏缓冲**：无需额外创建 Layer 或 Shader 缓冲区，完全在主画布上下文流水线中执行；
3. **帧率保障**：在 1000 块碎片场景下仍能保持 60fps/120fps 的丝滑满帧表现。
