## 2026-08-23 21:36 - 修复进入游戏界面后持续闪烁与无法操作问题

- `lib/pages/game_page.dart`：
  - 修复生命周期缺陷：原先在 `build()` 方法内部执行 `GameWidget(game: _game = JigsawPuzzleGame(...))`，导致每秒计时器触发 `setState` 或进度更新时，GameWidget 被迫反复销毁并重新初始化 `JigsawPuzzleGame` 实例（造成每秒清屏、打散与闪烁）。
  - 将 `JigsawPuzzleGame` 实例的生命周期绑定至 State，仅在图片加载完成或玩家主动点击「重新开始」时初始化一次，避免重复构建。
- `lib/game/jigsaw_puzzle_game.dart`：
  - 优化初始碎片散落算法 `_generateScatterPosition`，基于实际视口尺寸在屏幕四周边缘自适应分布，避免超出可视区域或与棋盘中心发生初始重叠。
