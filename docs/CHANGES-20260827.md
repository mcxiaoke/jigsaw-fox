## [2026-08-27 12:50 GMT+8] `scripts/imgcrop.py` 新增 `--detector usm`（反向锐化细节层检测器）

### 变更内容
1. **新增 USM 细节层检测器**（即主流锐化算法的反向）：
   - 新增 `_usm_detail(g, radius)` 计算 `D = |I - GaussianBlur(I)|`，与 USM 锐化判断"哪里需要锐化"的度量完全一致；
   - 原理对应：锐化在 D 高处加强、低处不动；本脚本反向——D 高处保留（主体/细节），D 低处裁掉（虚化/纯色/平滑渐变背景）；
   - 相比默认 `std`（邻域局部标准差），USM 对"缓慢过渡的平滑渐变背景"同样给出近 0 响应（高斯模糊保留线性斜坡），剔除更彻底。
2. **CLI 新增 `--detector {std,usm}`**（默认 `std`，保持向后兼容与既有校准）：`usm` 模式复用 `--win` 作为高斯模糊半径、`--trim-tol` 作为相对背景基线的额外阈值。
3. **校准结论（macaw 3008x2000 + temp/daily 42 张）**：
   - 同 `--trim-tol` 下 `usm` 与 `std` 行为高度一致，均能在 tol=12 完整保留鹦鹉头部；
   - `usm` 略敏感（同 tol 裁切稍多），高 tol 时衰减更陡（tol=24 会过度裁切）；
   - 推荐：保守用 `--detector usm --trim-tol 8`；沿用默认则 `--detector std --trim-tol 12` 已充分校准（daily 过裁 0 张）。

## [2026-08-27 12:27 GMT+8] 集成亮度驱动与噪声门限自适应锐化算法（Luma-Gated CAS）

### 变更内容
1. **独立亮度驱动与噪声门限锐化函数 (`lib/logic/image_upscaler.dart`)**：
   - **新增感知亮度加权**：基于 $Y = 0.299R + 0.587G + 0.114B$ 统一计算锐化系数，彻底杜绝 RGB 通道独立锐化带来的彩色噪点（Chroma Noise）；
   - **局部对比度噪声门限 (Noise Gate)**：计算 3x3 邻域亮度极差 $\Delta Y = Y_{\max} - Y_{\min}$，低于门限（默认 8.0）直接 Early Exit 跳过锐化，天空/皮肤/纯色背景底噪 100% 抹平；
   - **SmoothStep 平滑过渡**：在微弱纹理区域平滑过渡锐化系数，强轮廓区（发丝/羽毛/边缘）全强度锐化；
   - **自适应分辨率锐化强度**：根据原图小图尺寸自适应调整有效锐化强度；
   - **独立函数化与向下兼容**：提供独立函数 `applyLumaGatedCAS`，并在 `processPipeline` 与 `upscaleBytes` 中新增 `useLumaGated` 等可配置参数，默认开启；
2. **测试与对比生成工具 (`tool/generate_upscale_comparisons.dart`)**：
   - 编写独立测试工具，支持从 `temp/testimages/` 批量生成基准插值、旧版 CAS 与新版 Luma-Gated CAS 的三联并排对比图与局部特写图至 `temp/comparisons/`；
3. **测试覆盖与静态分析**：

## [2026-08-27 12:18 GMT+8] 新增素材预处理脚本 `scripts/imgcrop.py`（去背景裁切 + 比例裁切 + 缩放）

### 变更内容
1. **核心脚本 `scripts/imgcrop.py`**：用于拼图素材预处理，对输入目录图片批量执行四步：
   - 自动裁掉四周大面积虚化/纯色背景（内容感知）；
   - 按 3:4 / 2:3 / 1:1 自动选最接近原图长宽比之一居中裁切（含横竖镜像）；
   - 缩放使短边 ≤ 指定值（默认 1600，仅缩小不放大）；
   - 输出 jpg/png，递归处理子目录并生成 `report.csv`。
2. **背景裁切算法**（关键决策，迭代至 v3）：由初版「Lab 颜色距离洪泛」→ v2「梯度幅值逐边推进」→ **v3「窗口化局部标准差 + 各边基线相对阈值」**（当前）。
   - v1（颜色洪泛）：鹦鹉绿羽与绿虚化同色，头部被切 385px；且阈值方向不直观、存在跳变。
   - v2（梯度幅值）：改善但单像素梯度对噪点敏感，行内取 MAX 易被孤立高对比像素误触发。
   - v3（当前，按用户建议实现）：每边从外到内逐行/列检测，用积分图计算每像素 **9×9 邻域局部标准差**（`--win` 可调），取行/列 **90 百分位**抗噪点；各边独立取最外缘中位数为**背景基线**，当区域对比度 > 基线 + `--trim-tol` 时停止。鹦鹉实测 tol=12 头部完整保留（冠/眼/喙/黄颊均无损），虚化边缘干净去除。
3. **可调参数**：
   - `--trim-tol`（0-255，默认 **12**）：相对背景基线的额外对比度阈值。**越小越保守、留得越多；越大裁得越多**。
   - `--win`（邻域半径 px，默认 **4** ≈ 9×9 窗口）：控制局部对比度检测的窗口大小。
4. **CLI 参数**：`input_dir [output_dir] --format --quality --aspect --short --no-trim --trim-tol --margin --no-recursive --dry-run`。
5. **输出命名与落盘（补充）**：
   - 输出文件名统一加 `-cropped` 后缀（如 `macaw.jpg` → `macaw-cropped.jpg`），避免覆盖原图；
   - `output_dir` 改为可选，不指定时默认输出到**源目录**；源目录模式下对旧 `-cropped` 输出直接覆盖（不产生 `_1` 重复文件），且自动跳过目录内已有的 `-cropped` 文件（避免重复处理 / 产生 `-cropped-cropped`）。
