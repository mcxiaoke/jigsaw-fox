## [2026-08-27 11:13 GMT+8] 重构工业级图片缓存系统：三级分级流水线、主线程零同步 I/O 与并发受控调度引擎

   - 彻底移除 `existsSync`、`lengthSync`、`readAsBytesSync` 等所有主线程同步磁盘系统调用；

## [2026-08-27 10:48 GMT+8] 实现分层解耦的独立图片缓存基础设施 (ImageCacheManager) 与自制关卡响应式自动刷新

### 变更内容
1. **独立分层图片缓存与缩略图引擎基础设施 (`lib/logic/cache/`)**：
   - **核心缓存引擎 (`image_cache_manager.dart`)**：纯 Dart 逻辑单例门面，无任何 Flutter Widget 依赖，提供磁盘缩略图持久化、哈希索引、同步命中检查、请求并发去重合并（`_inFlightTasks`）、缓存大小统计与一键清理功能；
   - **后台 Isolate 缩略图生成器 (`thumbnail_generator.dart`)**：利用 `package:image` 在后台独立 Isolate 中实现对各类图片（JPG/PNG/WEBP/BMP）的高性能下采样与高质量 JPEG 编码（默认 360px），杜绝主线程卡顿；
   - **Flutter 渲染适配层 (`app_cached_image_provider.dart`)**：继承官方 `ImageProvider`，将底层缩略图缓存透明桥接至 Flutter 渲染管线，支持原生 `Image`、`DecorationImage` 等标准组件；
   - **可选 UI 便捷组件 (`lib/widgets/app_cached_image.dart`)**：上层通用封装，支持本地文件、Assets、网络链接与内存字节，集成 `ResizeImage` 限制 GPU 显存解码，内置平滑淡入动画（FadeIn）、骨架占位与错误优雅回退；
   - **全局 ImageCache 调优 (`lib/main.dart`)**：配置 `PaintingBinding.instance.imageCache` 内存上限（500 张对象 / 150MB 显存），防止高分辨率图片爆显存。
2. **多场景缩略图主动预热（Pre-warm Pipeline）**：

   - **自制关卡裁切保存** (`CropPuzzlePage._saveAndCreate`)：导出大图同时异步预生成缩略图；
