> **版本**: v1.0  
> **制定日期**: 2026-09-01

## 1. 实施原则

1. **先做地基，再做装修**：P0 未通过色彩/字体/圆角统一验收前，禁止进入 P1。
2. **绝不各页面各玩各的**：任何页面改动必须引用 `AppPalette` 和 `AppTextStyles` 常量，禁止硬编码色值。
3. **游戏感优先于功能完备**：宁可少做一个设置项，也要让通关结算和对局体验先达标。
4. **每阶段必须有截图对比**：阶段完成后截取关键页面，与当前版本并列对比，确认方向正确。

## 2. P0：地基层（视觉统一框架）

**工期**: 1–2 周  
**验收标准**: 打开任意两个页面，它们看起来“像同一个 App”，而非“两个不同项目拼在一起”。

### 2.1 色彩体系（替代临时绿色）

| 色彩角色 | 日间模式 | 夜间模式（默认） | 用途 |
|---|---|---|---|
| 页面底色 | `#F5F1EB` 暖米灰 | `#1A1D24` 深炭灰 | 全局背景 |
| 卡片/面板底色 | `#FFFFFF` | `#252A33` 深灰蓝 | 内容容器 |
| 主文字 | `#1E232C` 深炭 | `#E8EAEE` 暖白 | 标题与正文 |
| 次要文字 | `#6B7280` 中灰 | `#9CA3AF` 浅灰 | 描述、辅助信息 |
| 禁用/锁定文字 | `#9CA3AF` | `#4B5563` | 未解锁项 |
| 分割线/边框 | `#E5E0D8` | `#2E3440` | 细线分隔 |
| **强调色（品牌色）** | `#D4963C` 琥珀金 | `#D4963C` 琥珀金 | 选中态、高亮、按钮、星级 |
| 金币/奖励色 | `#F0B840` 亮金 | `#F0B840` 亮金 | 货币、奖励徽章 |

**语义色（仅在对应场景使用，绝不泛化）**：

| 语义 | 色值 | 使用场景 |
|---|---|---|
| 成功 | `#3D8B5F` 暗松绿 | 拼图正确吸附、操作成功 |
| 警告 | `#E8A339` 暖橙 | 限时将尽、操作需谨慎 |
| 错误 | `#D64B4B` 砖红 | 拼图放错位置、网络失败 |
| 信息 | `#5B8DB8` 灰蓝 | 提示、说明、未解锁图标 |

**产出物**: Dart `AppPalette` 类（含 `light`/`dark` 工厂 + `of(BuildContext)` 访问器）。

### 2.2 字体层级

| 层级 | 尺寸 | 字重 | 用途 |
|---|---|---|---|
| H1 页面标题 | 28–32px | w700 | 主页顶部、对局标题 |
| H2 模块标题 | 20–24px | w600 | 卡片标题、Sheet 标题 |
| Body 正文 | 14–16px | w400 | 描述、规则说明 |
| Caption 辅助 | 12px | w400 | 时间、数量角标、标签 |
| Mono 等宽数字 | 28–36px | w700 | 统计数字、计时器、金币数 |

**产出物**: Dart `AppTextStyles` 类（支持主题切换时自动反色）。

### 2.3 全局圆角与阴影

| 元素 | 圆角 | 阴影 |
|---|---|---|
| 大卡片 / 面板 | `Radius.circular(24)` | `BoxShadow(color: Colors.black12, blurRadius: 12, offset: Offset(0, 4))` |
| 按钮（主要） | `Radius.circular(16)` | `BoxShadow(color: Colors.black.withOpacity(0.08), blurRadius: 8)` |
| 按钮（次要/幽灵） | `Radius.circular(12)` | 无 |
| 小标签 / 徽章 | `Radius.circular(8)` | 无 |
| 底部 Sheet | 顶部 `Radius.circular(24)` | 无（由系统底层遮罩提供深度） |

### 2.4 全局提示系统（严禁原生 SnackBar）

所有游戏内提示统一为 **顶部 HUD 气泡**：
- 位置：状态栏下方，顶部滑入（`SlideTransition` from `-y`）。
- 样式：深炭褐底 `#2A2F3A` + 1px 琥珀金微边框 + 圆角 24 + 图标 + 文字。
- 时长：成功/信息 2.5 秒；错误 4 秒（带“重试”按钮）。
- 动画：滑入 → 停留 → 向上滑出；最多同时显示 1 条，新提示顶掉旧提示。

**产出物**: `GameToast` 组件。

### 2.5 底部导航图标

- 风格：面性图标（24px，填充而非描边），线条粗细 2px。
- 选中态：琥珀金图标 + 微弱外发光（`BoxShadow(color: #D4963C.withOpacity(0.3), blurRadius: 8)`）+ 微缩放 `scale: 1.05`。
- 非选中态：浅灰 `#9CA3AF`。
- 动画：切换时 200ms 弹性缓动（`Curves.easeOutBack`）。

**产出物**: 新 icon 资源（SVG/PNG）+ 导航栏样式封装。

## 3. P1：核心体验层（高频页面游戏化）

**工期**: 2–3 周（P0 验收后启动）  
**验收标准**: 真实用户试玩时，愿意主动点开成就页；对局时手指不再遮挡碎片关键区域。

### 3.1 主页 & 关卡列表

| 改进项 | 具体方案 |
|---|---|
| 今日挑战 Banner | 全出血大图（今日拼图原图）+ 底部渐变遮罩（黑 → 透明）。日期与标题用暖白粗体压在遮罩上。右上角倒计时徽章 `⏳ 04:22:10` + 首通奖励 `🪙+50` 徽标。取消当前蓝色背景块。 |
| 筛选栏整合 | 第一行难度标签改为深色 Segmented Control（深灰底 + 琥珀金选中），高度 40px。第二行分类标签改为横向滚动 Chip 栏，默认显示前 5 个 + “更多”展开。两行总高度 ≤ 90px。 |
| 关卡卡片 | 圆角 24px。已解锁保持原图色彩。未解锁：饱和度降至 30% + 叠加 `rgba(26,29,36,0.5)` 暗角 + 居中半透明锁图标（灰蓝 `#5B8DB8`）。淘汰黑白打印机效果。 |
| 卡片信息层级 | “#1”编号移至左上角小药丸标签（深灰底 + 白字）；碎片数改为底部细进度条（如“已拼 3/25”）；三星评分放在卡片底部居中，琥珀金星形。 |
| 通关状态 | 移除正中央大绿勾！改为卡片右下角悬浮 3 颗金色立体星星（⭐⭐⭐），不遮挡图片核心区域。 |

### 3.2 关卡详情 & 难度选择（Bottom Sheet）

- 放弃居中纯白大弹窗，改用底部 Sheet（圆角 24 向上滑出），背景主页隐约可见，形成上下文关联。
- 顶部显示原图微缩 + 标题 + 作者/来源。
- 难度卡片改为中性灰底卡片，内嵌微型网格示意图（如 5×5 代表 25 块），选中态外框 2px 琥珀金 + 内部微光。
- 底部主按钮：“开始拼图”琥珀金实心大按钮；次要按钮：“收藏”空心按钮。

### 3.3 对局界面（核心玩法）

| 改进项 | 具体方案 |
|---|---|
| 碎片托盘筛选 | 托盘顶部增加分段控制：全部 / 仅边框块 / 仅中心块。默认“全部”。 |
| 拖拽防遮挡 | 手指接触碎片时，碎片向上偏移 30px + 缩放 1.1x + 8px 投影，释放后归位。 |
| 磁吸正反馈 | 碎片靠近正确位置时：① 碎片边缘发光（琥珀金 `#D4963C`）；② 放置正确瞬间播放轻脆“咔哒”音效 + Haptic 轻震；③ 金色微光粒子从拼接处向外扩散（持续 300ms）。 |
| 背景壁纸 | 提供“暖木纹/羊皮纸/星空/大理石”4 款预设，在设置中随时切换。 |

### 3.4 成就页仪表盘

- 顶部：弧形环状进度条（总解锁率，如 `12/25 (48%)`）；右侧横向滑动 4 组精致胶囊数据（总星数 ⭐、通关数 🖼️、已拼碎片 🧩、总时长 ⏱️）。
- 头衔系统：显示当前等级（如 Lv.3 资深拼手 → 进阶构图家 → 宗师）。
- 成就勋章墙：横向卡片。左侧个性化彩色矢量图标（已解锁金属质感 + 挂带；未解锁灰蓝石质封印）。中间标题 + 描述。右侧进度比例或跳动金色宝箱按钮（可领取状态）。
- 进度条语义色：铜 → 银 → 金渐变（对应普通 / 稀有 / 传说成就）。

## 4. P2：游戏化层（仪式感与正反馈）

**工期**: 2 周（P1 验收后启动）  
**验收标准**: 用户通关后“忍不住截图发朋友圈”。

### 4.1 通关结算动画（Victory Screen）

- 触发：最后一块拼图正确放置后，全屏渐变遮罩（300ms 淡入）。
- 内容：
  - 背景：礼花粒子（金色 + 琥珀色，向下飘落）。
  - 中央：完成拼图原图，边框 4px 琥珀金，微缩放弹入（`scale: 0.8 → 1.0`，`Curves.elasticOut`，500ms）。
  - 星级：3 颗星星依次点亮（每颗间隔 400ms，点亮时伴随“叮”音效 + 星芒粒子）。
  - 数据：用时 `02:34`、步数 `47`、奖励 `🪙 +30`，数字带翻滚动画（从 0 滚动到目标值，800ms）。
  - 按钮：“保存壁纸”（空心）、“分享成绩”（实心琥珀金）、“下一关”（实心琥珀金，最突出）。

### 4.2 每日挑战月历签到盘

- 进入每日挑战时先弹出当月月历：
  - 已签到日期：金色实心圆点。
  - 今日：脉冲光圈（呼吸动画）。
  - 未签到：灰色空心圆。
  - 连续签到奖励：底部进度条（“再签到 2 天获得 🪙+100”）。
- 完成当日挑战后：日期圆点内打勾，伴随金币飞入顶栏动画。

### 4.3 设置页游戏化

- 顶部玩家身份区：左侧狐狸头像占位（默认 icon 中的狐狸），右侧显示昵称 + “已游玩 X 小时 / 解锁 Y 项成就 / Lv.Z 头衔”。
- 资产 HUD 常驻顶部导航栏右侧：
  - `[🪙 120 +]` 金币胶囊（点击跳转商城/素材库）
  - `[⭐ 36]` 星级总数卡片
  - `[🏆 成就]` `[⚙️ 更多]`
- 外观设置前置：“默认壁纸背景”从子页提取到设置首页独立大卡片，提供 4 款精选壁纸实时预览切换。
- 设置项图标：全部替换为面性游戏风格，颜色统一灰蓝 `#5B8DB8`。

### 4.4 继续弹窗情感化

- 中断返回时弹出：
  - 文案：“小狐狸在等你完成这幅拼图呢 🦊”
  - 两按钮权重区分：
    - “继续挑战”——琥珀金实心大按钮
    - “退出”——灰底细线小按钮（弱化）

## 5. P3：进阶层（长期留存与社交）

**工期**: 1–2 周（P2 验收后启动，按需）  
**验收标准**: 用户有动力每天打开 App；有至少 5% 用户使用过分享功能。

### 5.1 桌面主题解锁系统

- 用金币解锁“星空 / 大理石 / 羊皮纸 / 木纹 / 樱花 / 海洋”等桌面背景。
- 解锁时在主页播放顶部丝带横幅通知（琥珀金底 + 深字，3 秒滑入滑出）。
- 已解锁主题在设置页以大卡片网格展示，带微缩预览图。

### 5.2 音效风格包

- 设置页增加“音效风格”选项：
  - 经典咔哒（默认）
  - 木质咬合（深沉）
  - 水晶清脆（明亮）
  - 卡通弹珠（儿童向）
- 拖拽和吸附时根据所选风格播放不同音效。

### 5.3 社交分享卡片生成器

- 通关结算页增加“生成分享卡片”：
  - 竖图 1080×1920
  - 内容：完成拼图原图居中 + 底部信息栏（用时、星级、步数）+ 右下角 App Logo（狐狸图标）
  - 风格：根据当前主题自动匹配背景纹理
  - 输出：PNG，唤起系统分享面板（微信 / 小红书 / Instagram）

### 5.4 狐狸吉祥物延展

- **主页**：左上角常驻小狐狸头像（点击弹出玩家资料弹窗）。
- **空状态**：
  - 无收藏：狐狸抱着空篮子，旁边文字“还没有收藏喜欢的拼图呢”。
  - 无网络：狐狸挠头，旁边文字“好像断网了，小狐狸找不到拼图”。
- **加载页**：狐狸转圈（Lottie/SVG 动画），底部进度条。
- **提示旁白**：部分 HUD 气泡左侧加上狐狸小头像，让提示更有温度。

## 6. 关键决策检查点

| 阶段 | 检查点 | 通过标准 |
|---|---|---|
| **P0 结束** | 截图对比 | 任意两个页面并排放在一起，风格统一，无绿色残留 |
| **P1 结束** | 用户试玩 | 3 名用户愿意主动点开成就页；对局时手指不遮挡碎片 |
| **P2 结束** | 情感测试 | 至少 1 名用户在通关后主动说“好看，想分享” |
| **P3 结束** | 数据验证 | 日活留存率提升（基线对比）；分享功能使用率 ≥ 5% |
