## 设置页语言切换后多 Tab 无感实时刷新修复与统一缓存失效机制 2026-09-07 09:17

- **问题背景**：用户在设置页由英文切换至中文后返回主页，发现「每日挑战」Tab（除 AppBar 外全页文案）与「图集」Tab（下半部 Collections 卡片与状态）未响应语言刷新，需退后台重启才更新；而「主页」Tab 却能正常刷新。
- **根本原因分析**：
  1. **MainScreen IndexedStack 中存在 const 阻断元素树更新**：lib/pages/main_screen.dart 中 DailyTabView 和 CollectionsTabView 声明为 const DailyTabView() 与 const CollectionsTabView()。当 MainScreen 因退回重绘时，Flutter 元素树检测到子组件指针 identical(oldWidget, newWidget) == true，直接跳过了对两者的 uild() 执行。而 HomeTabView 拥有动态闭包回调 onSwitchToDaily，非常量组件故其元素树重新执行了 uild()。
  2. **各 Tab State 缺少对 LocaleService 的响应式监听**：各 Tab 状态（_DailyTabViewState、_CollectionsTabViewState、_HomeTabViewState、_MyCenterTabViewState）均未订阅 LocaleService.instance，在静态 	 改变时缺乏触发 setState() 的通道。
  3. **UnifiedCatalogIndex 静态内存索引缓存失效机制缺失**：「我的」Tab 依赖的 UnifiedCatalogIndex 将多模块关卡的展示标题与副标题（如 	r.source.official、	r.game.titleLevel）缓存在静态内存中，语言切换时未调用 invalidate()，导致展示数据滞后。
  4. **CollectionsTabView 与 HomeTabView 残留写死中文字符串**：Banner 默认副标题 '限时活动挑战' 与角标 '限时活动'、空态文案 '暂无图集内容'、'下拉刷新同步官方资源'、'刷新同步'、'暂无图集' 写死，未走 	.events.* 与 	.collections.*。
- **修复方案与实施**：
  1. **移除 MainScreen 的 Tab const**：lib/pages/main_screen.dart 中将 const DailyTabView() 与 const CollectionsTabView() 转换为非 const，并使 _MainScreenState 订阅 LocaleService.instance 监听。
  2. **全面接入 LocaleService 动态监听**：
     - _DailyTabViewState：initState / dispose 中绑定与解绑 LocaleService.instance.addListener，收到通知即刻触发 setState 刷新。
     - _CollectionsTabViewState：接入 LocaleService.instance.addListener；将写死中文替换为 	.events.subFallback、	.events.badgeLimited、	.collections.emptyAll、	.collections.emptyHint、	.common.sync、	.collections.emptyCollections。
     - _HomeTabViewState：接入 LocaleService.instance.addListener；_TagBarDelegate.shouldRebuild 设为 	rue 确保标签栏标题动态更新；Banner 活动项改用 v.displayTitle / v.displayDesc；分类空态接入 	.home.emptyCategory 与 	.home.viewAll。
     - _MyCenterTabViewState：接入 LocaleService.instance.addListener，通知时主动调用 UnifiedCatalogIndex.invalidate() 并重新加载数据。
  3. **UnifiedCatalogIndex 自动化语言响应**：在 lib/logic/catalog_index.dart 中为 UnifiedCatalogIndex 注册 LocaleService 监听，语言变更时自动执行 invalidate()，杜绝脏数据。
  4. **自动化测试覆盖**：
     - 新增 	est/widgets/locale_switch_refresh_test.dart：在单个组件生命周期内模拟从 English → 打开 Settings 切换为 Chinese → 返回主页 → 遍历验证所有 4 个 Tab 及 AppBar、分类标签与操作项全部即时更新，再切回 English，验证全链路 0 延迟刷新且无需重启。
