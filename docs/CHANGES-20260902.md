## 修复 ChooseDifficultySheet 竖屏（2:3）预览图被压为 1:1 正方形的布局缺陷（2026-09-02 21:43 GMT+8）

- **背景与原因**：
  - 用户反馈：「daily难度选择界面，文字写2:3竖屏 实际预览图是正方形的，进去拼图确实是2:3竖屏；横屏的图预览图没问题」。
  - 原因剖析：`ChooseDifficultySheet` 预览卡片容器显式设置了 `width: double.infinity`，导致向子级 `AspectRatio` 传递了紧约束（Tight Width），当遇到竖屏（2:3）比例时，计算高度 540 超出 `maxHeight: 360` 触发尺寸截断，最终将组件强行夹紧成 360×360 正方形；横屏（3:2）因计算高度 240 < 360 未触顶截断因而视觉正常。
- **改动**：
  - [`lib/widgets/choose_difficulty_sheet.dart`](file:///c:/Home/Projects/jigsawpuzzle/lib/widgets/choose_difficulty_sheet.dart)：
    - 精准精简修复（仅改动 2 行）：
      - 移除预览卡片 `Container` 的 `width: double.infinity`，恢复水平松约束，使 `AspectRatio` 在受 `maxWidth: 520` 和 `maxHeight: 360` 限制时能双向自适应计算出标准的 `240×360`（2:3 竖屏），彻底消除正方形畸变。
      - `AspectRatio` 的比例统一切换为 `_aspectRatio.ratio`，确保与当前选中的难度格网（4×6 / 6×9）、切片预览线、标签说明严格对齐。
  - [`test/new_features_test.dart`](file:///c:/Home/Projects/jigsawpuzzle/test/new_features_test.dart)：
    - 新增测试用例 `ChooseDifficultySheet renders 2:3 vertical preview without square distortion`（包含 2:3 测试图 base64 模拟数据），断言 2:3 预览卡片在弹窗中宽度、高度与长宽比保持 2:3，杜绝未来回归。
- **验证**：

  - 单元与组件测试：`flutter test` 182 项全量通过（含新增 2:3 竖屏无变形测试）。

## 图片缓存：缩略图档位 enum 化 + 内存/缓存修复（2026-09-02）

### 类型安全：缩略图档位改为枚举
- 新增 `enum ThumbnailDimension { card(360), eventCover(720) }`（`lib/logic/cache/image_cache_manager.dart`），
  取代原先「任意 int + 向上收敛到 {360,720,1440}」的设计；调用方只能在两档中选择，从编译期杜绝
  传 360/500/600 等零散尺寸造成同图多份缩略图。

  prewarmThumbnail/isThumbnailCached/removeThumbnailForSource 等）的 `int targetDimension`
  参数改为 `ThumbnailDimension dimension`；删除 `kThumbnailDimensionBuckets` 与 `normalizeDimension()`。

- `AppCachedImage`：`targetWidth/targetHeight(int?)` → `targetDimension(ThumbnailDimension, 默认 card)`，
