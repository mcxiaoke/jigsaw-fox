## 图片缓存：缩略图档位 enum 化 + 内存/缓存修复（2026-09-02）

### 类型安全：缩略图档位改为枚举
- 新增 `enum ThumbnailDimension { card(360), eventCover(720) }`（`lib/logic/cache/image_cache_manager.dart`），
  取代原先「任意 int + 向上收敛到 {360,720,1440}」的设计；调用方只能在两档中选择，从编译期杜绝
  传 360/500/600 等零散尺寸造成同图多份缩略图。
- `ImageCacheManager` 全部公开 API（getCacheKey/getThumbnailBytes/getThumbnailFile/
  prewarmThumbnail/isThumbnailCached/removeThumbnailForSource 等）的 `int targetDimension`
  参数改为 `ThumbnailDimension dimension`；删除 `kThumbnailDimensionBuckets` 与 `normalizeDimension()`。
- `removeThumbnailForSource` 改为遍历 `ThumbnailDimension.values` 全档位失效。
- `AppCachedImageProvider` / `AppImageKey`：`targetDimension:int` → `dimension:ThumbnailDimension`。
- `AppCachedImage`：`targetWidth/targetHeight(int?)` → `targetDimension(ThumbnailDimension, 默认 card)`，
  所有分支统一 `ResizeImage(width: dimension.pixels)`。
- 调用点更新（11 处）：home_tab 今日挑战大卡与 events_tab 封面 → `eventCover(720)`；
  其余卡片（daily/event_levels/pack_levels/my_puzzles/素材匣/首页关卡）→ 默认 `card(360)`。
- 测试同步：`test/image_cache_manager_test.dart` 3 处 `dimension: ThumbnailDimension.card`；
  新增「ThumbnailDimension Enum Tests」组 3 例（档位值 / 同源不同档位键区分 / 全档位清理）。
- 缓存键结构（`thumb_<fnv63>_<pixels>.jpg`）与 hash 算法不变，已存在的 360 缩略图仍可命中，正向 360 键无迁移成本；负号键与旧档位文件首次启动自动清理。

### 解码期降采样（fix #1）
- `Image.memory` 补充 `cacheWidth`：victory_dialog 600、continue_dialog 1080、
  choose_difficulty_sheet 预览 1080、share_card_generator 1080、
  **GamePage 暂停缩略(300×160) 1080、全屏原图预览 1440**（大号缩略，避免超分图 50MiB 全量解码；GamePage 拼图核心仍用原图按设计保留）。
- `choose_difficulty_sheet._decodeImageSize` 改用 `ui.ImageDescriptor.encoded` 只解析头部取尺寸
  （零像素解码），并 `dispose()` buffer/descriptor，消除原 `instantiateImageCodec` 的位图/Codecs 泄漏。
- `game_page.dart:_loadHeaderColor` `crop_puzzle_page.dart:_decodeImage` 补充 `codec.dispose()` 与 `image.dispose()`，消除后台解码泄漏。

### 网络封面落地缓存（fix #3，events_tab）
- 新增 `AppCachedNetworkImageProvider`（`lib/logic/cache/app_cached_network_image_provider.dart`）与
  `ImageCacheManager.getNetworkThumbnailBytes()`：网络 URL 同样走 `L1 内存 → L2 磁盘 thumbnail_cache/thumb_<hash>_<dim>.jpg → L3 下载+后台缩略` 三级流水，与本地文件共用同一缓存目录/同一 `getCacheKey` 命名空间与 `EngineTaskQueue` 单飞去重。
- `AppCachedImage` 网络分支由 `NetworkImage`（无磁盘缓存、每次重联网）改为 `AppCachedNetworkImageProvider`，`events_tab_view.dart:121` 活动封面 `event.coverUrl` 无需页面额外改动即享磁盘缓存与 `eventCover(720)` 解码期降采样。
- 封面首次下载后由 `ThumbnailGenerator.generateThumbnailFromBytes` 在 Isolate 生成 720 缩略，后续命中 L1/L2 零网络；`getCacheSizeBytes/clearCache` 已覆盖网络缩略。

### 设置页缓存管理（fix #2）
- 设置页「数据管理」新增「缩略图缓存」行：显示占用（`getFormattedCacheSize`）+ 清理按钮（`clearCache`）。
- 全部失败 Toast 图标由 material `Icons.error_outline` 统一为 `PhosphorIconsRegular.warning`（风格一致）：设置页缓存清理、`my_puzzles_tab_view`、`event_levels_page`、`pack_levels_page` 共 5 处。

### 杂项
- FNV 掩码改为 63 位（`hash & 0x7FFFFFFFFFFFFFFF`），消除约 50% 负号文件名；正数键与旧算法一致。
  新增启动期孤儿清理：`_rebuildDiskKeyIndexAsync` 自动删除 `thumb_-*.jpg` 负号键与旧档位 `_600/_1440` 孤儿文件。
- `getCacheSizeBytes` 仅统计 `thumb_*.jpg`，避免误算目录内其它文件。
- `AppCachedImage` 移除死参数 `color: null / colorBlendMode`（实际着色由 `ColorFiltered` 完成）。
- `choose_difficulty_sheet.dart` 混合行尾统一为 LF。
