## [2026-08-30 10:29 GMT+8] 修复“锁定但未被吸附/视觉未贴边”的状态·视觉脱节（isSolved 与吸附阈值不一致）

**修改文件**：`lib/game/jigsaw_puzzle_game.dart`

**背景**：独立边缘碎片落在离正确槽位有一段距离处，被 `isLocked` 锁定却**没有自动吸过去、没有绿色边框、视觉未贴边**。根因：锁定原用 `PieceState.isSolved`（逐轴误差 ≤0.035），而吸附/位移用欧氏距离 ≤ `effectiveSnapDistance()`——两者阈值不一致，导致碎片可在“逐轴接近槽位(<0.035)但欧氏距离超出吸附阈值”的区带被锁定，但没真正吸附（无位移方向、无绿框），造成状态与视觉脱节。

**改动**：
- `updatePiecesStateAndPriorities` 锁定判定由 `isSolved && planted` 改为 **`planted && 到槽位欧氏距离 ≤ effectiveSnapDistance()`**（与 `resolveSnap` 使用同一阈值），实现“锁定 ⟺ 真正被吸附就位”。
- 锁定时**强制把视觉对齐到槽位**（`comp.position.setFrom(_normalizedToScreen(nx,ny))` + `scale=_zoom`），并在锁定转场补触发绿色吸附边框（`triggerSnapGlow`），保证“锁定即已贴槽、有绿框”。
- `game_layout_test.dart` 新增“边缘碎片逐像素逼近槽位”回归测试：从正确槽位左右各 80px 逐像素扫描，断言**任何时刻 `isLocked` ⟹ 视觉已贴槽**，且远离槽位不锁定、可被扫把回收；旧代码会在“逐轴 <0.035 但欧氏超阈值”的窄带区触发失败。
- `game_layout_test.dart` 新增 5 类典型场景覆盖：「#1#2 中间碎片及其中间组合可自由拖动(不锁定)」「#3#4#5 边缘/边缘组吸附锁定不可动、零散碎片补全边缘组合被吸附锁定」。

**校验**：`flutter analyze` 无 Error（仅既有 `_showPauseMenu` 未使用警告）；`flutter test` 111 项全通过；`flutter build windows --debug` 成功。

## [2026-08-30 10:12 GMT+8] 吸附/锁定改为“连通到边缘装配体”规则（参考 WebJigex 设计）

**修改文件**：`lib/logic/engine/puzzle_engine.dart`、`lib/game/jigsaw_puzzle_game.dart`、`test/logic/snap_algorithm_test.dart`

**背景**：上一版“局部锚定（边缘或邻接已就位片）”仍允许“两片内部碎片互认资质”形成小悬浮岛。经与成熟网页版 WebJigex（`temp/code/jigex-prog.pretty.js`）比对确认其设计：碎片永不锁死、吸附须有邻居，`isEdge` 只用于边缘筛选/装配识别。据此将判定升级为**连通性**规则：只有“已就位且 4-连通分量内含边缘碎片”的碎片（即从边框长出的装配体）才可锁定不可移动；未连通边缘的内部岛屿（单块或多块拼合）始终可自由拖动。

**改动**：
- `puzzle_engine.dart`：去掉 `isPlacementAnchored`，新增 `computePlantedPieceIds`（对 isSolved 碎片做 4-连通分量 BFS，分量含边缘片即视为“已植入”集合）与 `canSnapCluster`（集群含边缘片，或成员目标正交邻格已被植入装配体占据，才允许吸附）。
- `resolveSnap` 阶段一改用 `canSnapCluster` 门控：孤立内部碎片/岛屿不吸附到槽位、保持自由可拖动（对应 WebJigex“无邻居不吸附”）。
- `jigsaw_puzzle_game.dart` `updatePiecesStateAndPriorities` 锁定判定改为 `isPieceSolved && planted.contains(id)`：内部岛屿即便拼合成自由集群也绝不 `isLocked`。
- `snap_algorithm_test.dart` 新增/改写：「孤立内部碎片…不吸附锁定（连通到边缘规则）」「内部两片岛屿即使都位正且相邻，不连通边缘也不吸附锁定（4×4 真·内部岛）」「边缘碎片可独立吸附；与已就位装配体相邻的内部碎片也可吸附」。

## [2026-08-30 10:00 GMT+8] 修复“孤立中间碎片在正确位置被锁死/粘死”及“扫把无法归位”

**修改文件**：`lib/logic/engine/puzzle_engine.dart`、`lib/game/jigsaw_puzzle_game.dart`、`test/logic/snap_algorithm_test.dart`、`test/game_layout_test.dart`

**背景**：托盘模式下放大棋盘后，玩家会发现个别碎片“异常吸附在棋盘上”（既不在边缘、也无任何邻居却单独被锁定），导致无法移动、扫把也归不了位。日志（`temp/buglog.txt`，6×8 棋盘 id=34, r=4,c=2）证实：该碎片恰好落在自己的正确槽位 `(0.25, 0.6667)`，被 `resolveSnap` 阶段一按“靠近自身正确槽位即吸附”规则单独锁定成“空中孤岛”。这不符合现实拼图规则——碎片只有在“边缘”或“与已就位碎片相邻”时才应落地。

**改动**：
- `puzzle_engine.dart` 新增锚定判定 `isPlacementAnchored`（含 `isBorderPiece` 边界判断）：/碎片若处于棋盘边缘，或与某个已就位（正确槽位）的正交相邻碎片相接，才算“锚定”；同集群成员之间不互认（避免孤立岛两两互认资质）。
- `resolveSnap` 阶段一（棋盘槽位吸附）增加锚定门控：整个待吸附集群若未锚定，则拒绝吸附到槽位、保持游离可移动（仍可在阶段二与邻居试合并）。
- `jigsaw_puzzle_game.dart` `updatePiecesStateAndPriorities` 的锁定判定改为 `位置正确 && 锚定`：即便某碎片恰好位于正确槽位，只要无锚定就不得 `isLocked`，从而可被拖动/被扫把回收。
- 新增复现/回归测试：
  - `snap_algorithm_test.dart`：「孤立内部碎片即使位置正确也不吸附锁定」「边缘碎片可独立吸附；与已就位碎片相邻的内部碎片也可吸附」。
  - `game_layout_test.dart`：「棋盘上网格相邻的两块自由碎片松手即被自动合并成集群，且扫把无法归位」，记录既有“合并成集群后扫把只回收 clusterSize==1”行为基线。

**校验**：`flutter analyze` 无 Error；`flutter test` 106 项全通过。
