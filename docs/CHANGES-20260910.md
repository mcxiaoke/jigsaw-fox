## [Fix] ImageCacheManager 磁盘计数体系修复（外部 review 第 2 项：L2 覆盖写/删除计数漂移）

针对外部 review 指出 `_diskKeyIndex.add()` 覆盖写（返回 false）时 `_diskCacheBytes` 未减旧加新、长期覆写失准的问题，重构计数体系为精确增减：

- **结构**：`_diskKeyIndex` 由 `Set<String>` 改为 `Map<String, int>`（key → 字节大小），便于覆盖写/删除时取旧值精确增减；公共 API 零改动（`isThumbnailCached`/`diskCacheBytesForTest`/`getCacheSizeBytes` 全部不变）。
- **重建索引**（`_rebuildDiskKeyIndexAsync`）：扫描时先 `await entity.length()` 取 size，`_diskKeyIndex[fileName] = size` 并同步累加 `_diskCacheBytes`（原实现 add 与加计数分离，length 异常时会留下有 key 无计数的不一致）。
- **覆盖写**（本地 L3 与网络下载两条写盘路径）：先取 `previousSize = _diskKeyIndex[cacheKey]`，写入后 `_diskCacheBytes += newSize`，若为覆盖则再 `-= previousSize`，并加 `<0 → 0` 负值保护——新增只加新、覆盖净变化 = 新-旧，计数与磁盘一致。
- **删除路径**（`removeThumbnailForSource`）：移除索引时同步取旧 size 减计数（原代码删文件不移除计数，长期删除会虚高）。
- **读失败移除**（本地 L2 命中、网络 L2 命中、网络排队二次检查共 3 处）：`_diskKeyIndex.remove(cacheKey)` 返回值若非 null 则同步减计数，避免"索引已移除但计数未减"。
- **LRU 淘汰**：保持原实现（`entry.size` 来自 `stat()` 精确值，减除后 `Map.remove` 移除索引），无需改动。
- **clearCache**：`_diskKeyIndex.clear()` 适配 Map；`_diskCacheBytes = 0` 不变。

- `dart format`（仅 1 个改动文件，0 改动残留）。
- `flutter analyze --no-pub`：0 error / 0 warning（241 info 与基线 241~243 一致，无新增）。
- `flutter test --no-pub`：313 passed / 8 skipped 全量通过（含 LRU 淘汰计数断言与 clearCache 归零断言）。

- `daily_content_pipeline.dart`：`ensureMonthReady` 改包装器（key = `yyyyMm`），monthDir 已就绪检查随方法体整体下沉为 `_ensureMonthReadyImpl`；命名参数签名（含 `overrideToday`）保持不变。
