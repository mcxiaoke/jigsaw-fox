## 2026-08-23 23:14 - 拖拽/提示空指针崩溃修复：快照尺寸失步防护

- **崩溃根因 (`lib/game/jigsaw_puzzle_game.dart`)**：
  - 当保存的进度快照（`initialSnapshotJson`）与当前拼图尺寸（`rows/cols`）不匹配时，`_applyBoardState` 会先替换 `_boardState` 再逐块取 `_pieces[p.id]!`，中途抛 `Null check operator used on a null value` 被静默吞掉，导致 `_boardState`（如 16 块）与 `_pieces`（如 9 块）永久失步；
  - 此后任何碎片拖拽结束都会在 `handlePieceDragEnd` 的 `_pieces[p.id]!` 处崩溃，并级联抛出 NaN/布局等一连串异常。
- **根因修复**：`_applyBoardState` 恢复前校验 `rows/cols/pieces.length` 与当前拼图一致，不匹配的快照直接忽略（保持初始状态），杜绝状态失步。
- **防御加固**：`handlePieceDragEnd` 与 `hint()` 中对 `_pieces[p.id]` 做空值防护，即使出现未知失步也不崩溃、平滑跳过。
- **回归测试 (`test/game_layout_test.dart`)**：新增「快照尺寸与当前难度不匹配时，恢复与拖拽/连续提示都不应崩溃」用例，修复前可稳定复现、修复后通过。
- 验证：`flutter analyze` 零 issue，21 项测试全过。
