## [2026-08-27 20:35 GMT+8] 修复放大后手机端按住棋盘空白区域无法平移的回归 (`lib/pages/game_page.dart:602`, `lib/game/jigsaw_puzzle_game.dart:826`)

### 根因分析
1. **回归提交定位**：`202129e`（fix: resolve code review defects）将单指空白平移从 `GamePage` 的 `Listener` 原生指针处理（`_onPointerMove` 中 `panBy(event.delta)`）迁移至 Flame `JigsawPuzzleGame.onPanUpdate` 的 `PanDetector`，意图消除“Listener + PanDetector 双重调用导致的 2 倍速平移”。
2. **失效机理**：`PuzzlePieceComponent` 使用 `DragCallbacks`，其底层由 `MultiDragScaleDispatcher` + `MultiDragScaleGestureRecognizer` 驱动。该识别器在 `hasDrag=true` 且 `hasScale=false` 时，**任意触摸移动即在手势竞技场中 `accept`**，直接抢占 `PanGestureRecognizer`。因此只要存在任意 `DragCallbacks` 组件，`Game` 层面的 `PanDetector.onPanUpdate` 在空白区域也永远无法赢得竞技场，导致手机端单指拖空白完全无响应；而 `Listener` 的原生 `PointerMoveEvent` 不参与手势竞技场，之前一直有效。
3. **触发现象**：仅在 `zoom > 1.0` 且未抓取任何碎片（`!isDraggingAnyPiece`）时才允许平移，桌面端中键平移与双指捏合缩放不受影响，故表现为“放大后手机单指按住空白无法移动”。

### 修复方案
1. **`lib/pages/game_page.dart:602`**：在 `_onPointerMove` 中恢复单指空白平移分支：
   ```dart
   else if (_game != null && _game!.zoom > 1.0 && _pointerPositions.length == 1
       && !_game!.isDraggingAnyPiece
       && (_game!.isTabletop || event.localPosition.dy < _game!.trayPosition.y)) {
     _game!.panBy(Vector2(event.delta.dx, event.delta.dy));
   }
   ```
   明确注释“使用 Listener 原生 pointer delta 直接驱动，避免 Flame PanDetector 与 DragCallbacks 的手势竞技场冲突”。
2. **`lib/game/jigsaw_puzzle_game.dart:826`**：移除 `onPanUpdate` 中的空白平移逻辑，保留空实现并补充注释说明：空白平移已由 `GamePage` 统一处理，此处不再处理以避免竞技场抢占与双重速度。`flutter analyze` 由 1 issue（unnecessary_overrides）恢复为 0 issues。
3. **兼容性**：双指捏合缩放（`_pointerPositions.length >=2`）、中键平移（`kMiddleMouseButton`）、托盘横向滚动（`TrayBackgroundComponent.onDragUpdate`）均保持原有逻辑不变。

- 逻辑回归：放大后手机单指按住棋盘空白区域可正常平移，双指缩放与碎片拖拽不受影响
