  - **托盘区域物理坐标校验与手势防御**：新增 `isPointInTrayArea(Vector2 pos)` 方法，在 `PuzzlePieceComponent.onTapDown` 与 `onDragStart` 中增加物理位置双重校验，杜绝碎片因异常状态被误判为托盘滚动而死锁无法抓取拖拽；
  - **组件未挂载动画防护**：在 `PuzzlePieceComponent.animateTo` 与 `animateScaleTo` 增加未挂载分支直接设置最终坐标与缩放，消除离线/非挂载状态下 Flame 抛出的 `EffectTarget.target` 空指针断言。

## 2026-09-17 09:30 修复级联合并受影响碎片同步、didMerge状态丢失及定海神针槽位保护漏洞

- **问题修复（`lib/logic/engine/puzzle_engine.dart`）**：
  - **受影响碎片同步补全（Bug 1）**：`_mergeAllAdjacentClusters` 支持传入 `affectedPieceIds`，发生级联合并时将新合并簇全部碎片 ID 写入集合并传回 `BoardTransitionResult.affectedPieceIds`，解决 UI 层（Flame 组件）漏掉 `animateTo` 导致视觉裂缝未闭合及下次拖拽瞬移闪现问题；
  - **级联合并状态回传（Bug 2）**：`_mergeAllAdjacentClusters` 返回 `(pieces, didMerge)` 元组，即使阶段一/二未吸附，阶段三级联合并也会正确将 `didMerge` 标记为 `true`，杜绝因未标记吸附导致游戏层误判为“未吸附”而丢弃合并状态；
  - **定海神针槽位绝对保护（Bug 3）**：在阶段二邻居合并与阶段三级联合并的定海神针决策中，增加“槽位就位保护”优先级（已在正确槽位 `isSolved` 的碎片/装配体拥有绝对不可动摇权），杜绝平手（1对1）或浮动大簇将已吸附在槽位上的碎片拽离槽位；
  - **度量统一微调**：阶段一坐标锁定窗口判据由逐轴统一为欧氏距离 `Point.distanceTo(Point(0,0)) <= lockEps`。

  - 断言级联合并产物的 `affectedPieceIds` 包含所有合并碎片；
  - 增加“已就位槽位碎片绝不被浮动同规模单片平移拽走”测试；
  - 增加“已就位小规模槽位装配体绝不被浮动大规模集群平移拽走”测试。

## 2026-09-17 09:14 修复 code-review 4.1/4.2：通关容差单一化 + 级联合并欧氏阈值与平移对齐

- **问题来源**：`docs/code-review-full-20260916.md` P1 严重问题 4.1（三套容差常量互不一致，高片数下可能误判通关）与 4.2（级联合并只改 clusterId 不做平移对齐，且用绝对 epsilon 判定）。完整方案见 `docs/code-review-snap-merge-fix-plan-20260917.md`。
- **4.1 容差源头统一（`lib/logic/models/puzzle_state.dart`）**：
  - 新增顶层常量 `puzzleSnapRatio = 0.40`、`solvedCapEpsilon = 0.035`、`solvedEpsilonRatio = 0.5` 与函数 `solvedEpsilonFor(rows, cols) = min(0.035, min(1/cols, 1/rows) × 0.40 × 0.5)`，作为通关判定的唯一容差源（放 model 层，避免 engine ↔ state 循环依赖）；
  - `PieceState.isSolved` 新增可选参数 `epsilon`，默认使用 `solvedEpsilonFor`；判定由逐轴绝对阈值改为欧氏距离 `Point(nx-tnx, ny-tny).distanceTo(Point(0,0)) <= e`；
  - `PuzzleBoardState.isSolved` / `isEdgeComplete` 保持语义不变（逐片调用底层判定）。
  - **数值性质**：N≤5 时取 0.035 原值（零回归）；N≥6 起取 `0.2/N`（吸附阈值 `0.4/N` 的一半），通关容差恒 ≤ 吸附阈值，"锁定时判通关、判定成功却未吸附"的矛盾数学上消除。
- **4.1 吸附侧联动（`lib/logic/engine/puzzle_engine.dart`）**：
  - `defaultSnapRatio = puzzleSnapRatio`，吸附阈值单一来源；
  - 装配锁定窗口 `:_lockPieceIfSolved` 由字面量 `0.05` 改为 `min(0.05, snapDist)`，锁定判定与当前档位吸附阈值动态联动（正常吸附路径锁定归零误差，玩家无感知；极端高片数下避免锁定窗口大于吸附窗口）。
- **4.2 级联合并可靠化（`lib/logic/engine/puzzle_engine.dart`）**：
  - `_mergeAllAdjacentClusters` 调用处（阶段三）传入与阶段一/二同一个 `snapDist`（`epsilon: snapDist`），不再使用绝对常量 0.035；
  - 级联内判定由逐轴 `abs(dx)<=epsilon && abs(dy)<=epsilon` 改为欧氏 `offsetError <= epsilon`（与吸附判定 `_isSnapped` 口径一致）；
  - 合并前按阶段二"小簇向大簇平移"规则，用既有 `_translateCluster` 对源簇平移 (dx, dy) 做对齐再 remap clusterId（方向规则：countA≥countB 时译 A 为 -dx/-dy... 具体与阶段二一致），消除"只改 id 不平移"导致的裂缝被永久固化；`clusterSizes` 同步维护，`result` 由 final 改为可变。
  - 消费面受益：`computePlantedPieceIds`、`hintFor`、`solvedCount`、`missingPieceCheck`、快照进度/恢复判断（`snapshot_store.dart:479`、`resume_helper.dart:72`）自动使用新容差。
- **测试（`test/logic/snap_algorithm_test.dart` 新增 4 用例）**：
  - `solvedEpsilonFor` 数值表（3×3/5×5 取 0.035，12×12/24×24 取 0.2/N）；
  - `isSolved` 欧氏判定 + 收紧验证（12×12 漂移 0.03 判未就位）+ 小网格零回退（3×3 漂移 0.02 仍判就位）；
  - 级联合并：1×3 板漂移 0.09 的中间片合并后相对坐标严格对齐（0 误差）；
  - 级联合并拒焊：24×24 对角漂移 0.02（√2×0.02>0.2/24）不合并。
