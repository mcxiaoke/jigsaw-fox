- **问题与排查**:
  1. **关窗卡顿与沙漏**: Windows 版关窗后出现 1~2 秒鼠标沙漏与磁盘卡顿；根因为 `flutter_inappwebview_windows` 插件在 UCRT `execute_onexit_table` 阶段触发 `coremessaging.dll` `0xc0000602 Fail Fast` 崩溃，导致系统 `WerFault.exe` 强行写入 35MB CrashDump。
  2. **WebView2 运行环境安全**: 部分精简版/LTSC Windows 系统可能未预装 Microsoft Edge WebView2 Runtime，若直接打开搜图将导致组件失败或页面卡死；且其他模块不应反向依赖 `main.dart`。
  3. **第三方库选型验证**: 深度调研与实测 `zikzak_inappwebview` 发现其 Windows 端实现严重缺失（`onDownloadStart`、`shouldOverrideUrlLoading`、生命周期均为空实现），因此保持官方稳定版 `flutter_inappwebview: ^6.1.5` 并彻底清理了无用的 `webview_flutter`、`desktop_webview_window`。
- **改动**:
  1. **瞬时退出防护**: `main.cpp` 在主消息循环退出并完成 COM 反初始化后，调用 `::TerminateProcess(::GetCurrentProcess(), 0);` 瞬时结束进程，跳过第三方 DLL 的 UCRT 退出析构冲突与 Dump 写入，实现 0ms 干净退出。
  2. **环境探测服务**: 新增 `WebViewService` 独立服务，解耦 `main.dart`；启动时通过官方标准接口 `WebViewEnvironment.getAvailableVersion()` 静默探测 WebView2，若缺失则标记 `isOnlineSearchAvailable = false`。
  3. **不改布局 + 拦截弹 Toast**: 「我的拼图」保持原有双卡片外观；当检测到无 WebView2 时，点击「在线搜图」直接弹出友好 `GameToast` 拦截，阻断底层组件创建，彻底杜绝崩溃与无限转圈。
  4. **专项单元测试**: 新增 `test/services/webview_service_test.dart`（5项测试全部通过），全量覆盖多平台与各种异常分支。
