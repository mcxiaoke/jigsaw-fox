### Fix: 卡片缩略图"十几秒不出图"最小修复——原图直出快路径

- **背景**: 用户反馈关卡原图已就绪（点进选择难度面板秒开大图）但卡片缩略图等待十几秒甚至更久不显示。根因：`AppCachedImageProvider._loadAsync` 在 L1/L2 缩略图缓存未命中时，会把生成任务推入全局 `EngineTaskQueue`（并发 2~4）排队纯 Dart 软解（单张 0.5~1.5s），一屏 20~30 张卡片排队导致 10~30s 延迟。
- **改动**（仅 `lib/logic/cache/app_cached_image_provider.dart` 一个文件）:
  1. 缩略图查询降级为"仅查已有缓存"：L1 内存 → L2 磁盘索引命中即返回，**绝不触发 L3 排队生成**；
  2. 未命中时原图直出：直接异步读原图字节，交由原生 C++ 解码器在 `getTargetSize` 阶段按档位长边（360/720）降采样，毫秒级出图（与选择难度面板同路径同速度）；
  3. 缓存探测异常平滑降级：任何缓存链路异常只记 warning 并继续原图直出，杜绝此前 `rethrow` 导致的永久裂图。
- **行为变化**: 该路径不再后台排队生成磁盘缩略图文件（无预热）；L2 缩略图仍由既有显式调用方（`download_manager`、`crop_puzzle_page`）按原逻辑生成。冷启动未命中时每次直读原图做原生降采样（毫秒级），属可接受代价。
