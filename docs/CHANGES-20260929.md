# 2026-09-29 变更概要

## 修复：声音系统跨平台播放失效与错位（sound_service / game_page）

### 问题现象
- Android 实机：拼图操作音效"有时没声音，感觉卡没了"，同一槽位第二次起大面积哑火。
- 跨平台：偶发播放的声音错误/错位（半截声、被截断后接另一声）。

### 根因（结合 audioplayers 6.8.1 + audioplayers_android 5.3.0 + audioplayers_windows 4.4.1 源码级分析）
1. **Android SoundPool 二次播放哑火（主因，audioplayers 已知问题）**：`lowLatency` 模式下播放自然结束无任何完成回调，`SoundPoolPlayer` 的 `streamId` 与 `WrappedPlayer.playing` 标志永久残留；后续 `play` 被原生 `if (!playing)` 早退，或退化为对已结束 stream 的无效 `resume`。池化复用槽位因此从第二次播放起全部哑掉，直到 stopAll/熔断"救活"。
2. **放弃路径 `resetSync()` 踩踏**：锁外二次检查发现 token 失效（被抢占/stopAll）时执行 `slot.resetSync()`，会清掉新占用者刚写入的状态并使其 token 失效，令抢槽成功的请求被迫弃播，甚至连环互踩（全员哑弹）。
3. **节流时间戳失败也消耗**：`_lastPlayMs` 在 dispatch 之前同步写入，超时熔断/播放失败/放弃后不回滚，一次失败连带吞掉节流窗内的下一次真实触发。
4. **Windows 同文件重播从中段续播**：原生 `Resume()` 不回零、Dart `play()` 不带 position，LRU 抢占未自然结束的槽且新旧文件相同时，从旧播放进度继续，产生半截错位声。
5. **时长估算偏大 1.5~2 倍**：6 槽归还偏晚，全忙概率放大，LRU 抢占截断频发。
6. **Windows/Android `inactive` 即 stopAll**：桌面失焦、通知栏下拉等"仍在前台"场景误断正在播放的尾音。

### 修复内容（`lib/services/sound_service.dart`）
- **stop-before-play**：每次起播前先 `player.stop()` 复位原生状态（带 token/代际复核）。同时修复 Android streamId/playing 残留哑火与 Windows 中段续播（audioplayers 官方 workaround）。
- **放弃分支不再 `resetSync`**：槽位已易主时直接放弃，不触碰新占用者状态。
- **节流移入锁内 + 失败回滚**：`_lastPlayMs` 在锁内判定并写入，超时/失败/放弃时按"仍是本次写入值"条件回滚，真实触发不再被失败连带吞掉。
- **`play()` 不再每次传 `mode`**：`setPlayerMode(lowLatency)` 已在建池时设置，省去每次播放的冗余平台往返。
- **`_durationFor` 按实测校准**（实际时长 + 100ms 缓冲，脚本 `temp/measure_wav.py` 实测全部 27 个 wav header）：place 150→120、snap 200→140、win 1500→1350、coinsFly 1500→1400、hint 1300→1200 等，槽位周转加快、抢占率下降。
- **建池自愈**：判定条件改为 `_pool.length >= _kPoolSize`，单个槽位创建失败跳过不中断，池未满时下次调用继续补建（原来半建状态会永久残缺）。
- **`stopAll` 无条件补发 stop**：防止"估算早于实际播完导致 isBusy 已归 false"的原生残留声漏停。

### 修复内容（`lib/pages/game_page.dart`）
- `didChangeAppLifecycleState`：仅 `paused/hidden/detached` 才 `stopAll()`；`inactive`（Windows 失焦 / Android 通知栏下拉）保持声音，仅暂停计时与落盘。

### 测试
- `test/services/sound_service_test.dart`：时长表断言同步校准值（win 1350ms 等）；`allAssets` 断言维持 27。
- `flutter analyze` 无问题；`flutter test` 395 全部通过；`flutter build windows --debug` 通过；`flutter test integration_test/app_test.dart -d windows` 通过。
