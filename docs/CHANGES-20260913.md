# JigsawFox Changes - 2026-09-13

## 14:05 (GMT+8)

### Fix: 窗口尺寸变化不再复位缩放与平移（保留用户视野）

- **根因**：`_syncResizeTransform` 在每次真实尺寸变化时执行 `_setZoom(1)` + `_panOffset.setZero()`，
  于是 Windows 拖拽/最大化窗口、移动端旋转屏幕等都会把用户放大好的视图清成 1.0x。
- **改动**（`lib/game/jigsaw_puzzle_game.dart`）：
  - `onGameResize` 在 `_computeLayout()` **之前**记录"旧几何 + 旧视口"下的归一化视图中心（新增
    `_normalizedViewCenter`），并在 `onLoad` 结束时记录 `_lastGameSize` 作为基准尺寸；
  - `_syncResizeTransform` 改为：保留 `_zoom` 并收敛到新几何推导出的 `_maxZoom` 之内
    （窗口变大 → 碎片变大 → `maxZoom` 下降，不收敛会出现 `_zoom > _maxZoom` 越界）；
    把同一归一化视图中心重新对准新视口中心后调用 `_clampPanOffset()` 收敛平移；
  - 新增 `_legalDomain()` 作为归一化合法摆放域的**唯一权威定义**，
    `_clampPanOffset` / `_legalDomainScreenRect` / 新增的 `_isNormalizedInDomain` 全部复用它，
    杜绝多处域定义漂移；
  - 游离碎片收拢判据由"是否在棋盘 `[0,1]` 内"升级为"是否在**当前模式合法域**内"：
    保留缩放后桌面散落碎片与"放大后合法停放在视口外"的碎片都不再被误判为越界而反复搬动
    （这是保留缩放的**必要前置**，否则改窗口仍会把碎片拽回）。
- **测试**：新增 2 条用例（尺寸变化保留缩放 / 保持视图中心 / 平移已收敛；窗口变大导致 `maxZoom`
  下降时缩放被收敛在 `maxZoom` 之内）。
- **验证**：`flutter analyze` 零告警；全量 362 项测试通过；Windows debug 构建与
  `integration_test/app_test.dart` 通过。

## 13:45 (GMT+8)

### Fix: 棋盘放大后已拼合碎片组无法移动、松手被钉回中部（核心拼图体验）

**现象**：棋盘放大后，多块已吸附的碎片组几乎拖不动、松手被钉回屏幕中部；单块碎片手感正常。
放大后也无法把拼好的碎片组推出可视区暂存。

**根因**：碎片拖拽与松手的"安全限位"以**屏幕视口**为边界，却用放大后的实际像素尺寸计算
**整簇包围盒**。当缩放 ≥ 2（各难度 `maxZoom` 恒为 2.0）且集群投影尺寸超过可用空间时，
`safeMin > safeMax`，边界区间被 `min/max` 兜底反转成**一个点**，落点退化为极少数离散位置
（实测 4×4 盘 2×2 集群垂直行程为 0）。该约束由提交 `a5deb7b`（2026-09-03）引入。

**改动**（`lib/game/jigsaw_puzzle_game.dart`）：

1. 拖拽/松手限位对象由"整簇包围盒"改为"**主片中心**"单点约束，新增唯一入口
   `_clampDragTarget` 与 `_dragCenterSafeBounds`，拖拽期与松手期共用，杜绝两处公式漂移；
   约束区间恒为正，数学上不可能退化。
2. 集群其余成员允许伸出视口 → 恢复"放大后把拼合好的碎片组推出可视区暂存"的能力；
   同时"主片中心恒在视口内"保证碎片永不完全消失、随时可再次抓取。
3. 窗口尺寸变化时的游离碎片收拢判据由"屏幕视口"改为"**合法摆放域**"
   （新增 `_legalDomainScreenRect`，与 `_clampPanOffset` 的归一化域同源），
   否则每次改窗口都会把已摆到视野外的碎片再次拽回、问题复发。
4. `missingPieceCheck`（仅剩 ≤2 块未归位时）的回收目标由"固定搬回屏幕正中"
   改为"就近落在视口内的完整可见位置"，避免刚刚推到视野边的碎片被瞬移回中央。

**测试**：重写 `test/game_layout_test.dart` 旧契约 1 条（原断言"拖出屏幕必须被拉回视口内"），
新增回归用例 2 条（极端拖拽下主片中心恒在安全区且松手不回中；放大 2.0x 后集群行程不再为 0
且可推出视口暂存）。全量 360 条测试通过；`flutter analyze` 无新增问题；
Windows debug 构建与 `integration_test/app_test.dart` 均通过。

  属独立问题，未纳入本次范围。
- 托盘模式下放大后的集群允许覆盖底部托盘区域：原"集群绝不遮挡托盘"约束与"允许移出视口"
  在数学上不可兼得，本次按后者（用户核心诉求）优先取舍。
