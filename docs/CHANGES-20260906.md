## 渲染性能与首帧优化：GameWidget 图层解耦 + 亚麻布纹材质着色器轻量化 2026-09-06 16:55

- **问题**：DevTools CPU Profiler 采样显示，进入拼图界面的首帧存在长达 7 秒的管线阻塞（`RendererBinding._handlePersistentFrameCallback` 与 `compositeFrame` 耗时过长），且常态下布纹绘制每秒产生大量 `drawRect` 混合开销。
- **根因**：
  1. `lib/pages/game_page.dart` 直接使用 `AnimatedOpacity` 包裹整张 `GameWidget`，首帧淡入阶段强迫 GPU 为整个游戏（底板 + 24 块拼图）分配整屏离屏缓冲（`OpacityLayer`），叠加未隔离的图层遍历；
  2. `lib/logic/rendering/linen_texture_manager.dart` 使用 `BlendMode.softLight` 非分离混合模式，导致首次遇到着色器时在主渲染线程触发即时编译卡顿（Shader Compilation Jank），且每帧片元着色器回读像素计算沉重。
- **修复**（3 文件）：
  - `docs/rendering-performance-optimization-plan-20260906.md`：详细撰写渲染优化系统设计文档，严密论证零破坏手势触控与拼图逻辑的隔离原则；
  - `lib/pages/game_page.dart`：`GameWidget` 外层包裹 `RepaintBoundary` 实现独立图层隔离；移除对其直接的 `AnimatedOpacity`，改用顶层单色遮罩淡出（`Stack` + `ColoredBox` + `AnimatedOpacity` + `IgnorePointer` + `onEnd` 自动卸载），保持平滑视觉淡入的同时彻底消除整屏离屏纹理分配；
  - `lib/logic/rendering/linen_texture_manager.dart`：亚麻布纹画笔切换为 GPU 硬件固定管线直接支持的 `BlendMode.srcOver`，消除软光着色器编译卡顿与片元回读。
- **验证**：`dart format` 0 changed；`flutter analyze` 0 issue；核心与组件单元测试 57/57 passed；`flutter build windows --debug` 编译通过。

## 优化音效服务性能：禁用 AudioPlayer 逐帧进度轮询 2026-09-06 16:15

- **问题**：DevTools CPU Profiler 采样显示 `AudioPlayer.getCurrentPosition`、`MethodChannel.invokeMethod` 及平台通道调用占用了 25%~30% 的 CPU 耗时，且伴随密集的微任务排队与 Future 回调。
- **根因**：`audioplayers: 6.8.1` 默认对每个播放器挂载 `FramePositionUpdater`，在起播后每帧通过 `SchedulerBinding` 向原生平台发送 `getCurrentPosition` 轮询播放进度；而拼图游戏内所有音效均为短音效，无需进度监听。
- **修复**：`lib/services/sound_service.dart` 在池化创建 `AudioPlayer` 时显式设置 `player.positionUpdater = null`，彻底消除音频帧回调轮询与平台通道洪泛。
- **验证**：`dart format` 0 changed；`flutter analyze` 0 issue；`flutter test test/services/sound_service_test.dart` 12/12 passed。
