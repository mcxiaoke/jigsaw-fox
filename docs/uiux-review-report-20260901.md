# Jigsaw Puzzle Game UI/UX 审查报告（整合版 v2.0）

> **审查日期**: 2026-09-01  
> **审查范围**: 基于实机截图（12 张）对主页、选关、难度选择、核心玩法、每日挑战、活动、自制关卡、成就统计、设置共 9 个模块进行全面评估  
> **目标**: 让产品达到公开发布水准，整体风格对齐主流休闲/益智游戏（Apple Arcade / Easybrain / Magic Jigsaw Puzzles 级别），而非工具类 App 质感。
> **说明**: 本报告整合了双份独立审查（`uiux-review-report-20260901.md` 与 `ui-ux-review-and-design-system-20260901.md`）的精华建议，去芜存菁、去重补漏，形成唯一落地规范。

---

## 1. 执行摘要

当前 App 功能结构已较完整，但在**视觉调性、色彩统一性、信息层级与游戏化表达**上存在明显短板。两份独立审查报告在诊断方向上高度一致（"像工具而非游戏"），但在解决方案上各有侧重。本整合版以**统一视觉规范**为底座，吸收两份报告中所有可落地、不冲突的精华建议，形成一份**可直接指导开发**的完整规范。

**核心问题**：
1. **色彩体系缺失** —— 临时绿色被滥用于所有场景，缺乏语义分层。
2. **页面风格割裂** —— 各模块独立设计，圆角、阴影、图标风格不统一。
3. **核心对局体验粗糙** —— 托盘碎片重叠、手指遮挡卡榫、吸附反馈不足。
4. **游戏感与仪式感缺失** —— 无通关动画、成就像报表、每日挑战缺乏打卡动力。

## 2. 统一视觉规范（全局约束）

以下规范是所有页面改动的底层约束。任何分页面建议均不得突破此框架。

### 2.1 色彩体系（替代临时绿色）

当前绿色的问题是：饱和度过高、缺乏层次、被用于所有场景。采用**"双主题 + 单品牌色 + 语义分层"**体系，确保全 App 色彩协调，绝不允许"各页面各玩各的"。

#### 2.1.1 主题色板

| 色彩角色 | 日间模式 | 夜间模式（默认） | 用途 |
|---|---|---|---|
| **页面底色** | `#F5F1EB` 暖米灰 | `#1A1D24` 深炭灰 | 全局背景，减少眼睛疲劳 |
| **卡片/面板底色** | `#FFFFFF` | `#252A33` 深灰蓝 | 内容容器，与底色拉开层次 |
| **主文字** | `#1E232C` 深炭 | `#E8EAEE` 暖白 | 标题与正文 |
| **次要文字** | `#6B7280` 中灰 | `#9CA3AF` 浅灰 | 描述、时间、辅助信息 |
| **禁用/锁定文字** | `#9CA3AF` | `#4B5563` | 未解锁、不可操作项 |
| **分割线/边框** | `#E5E0D8` | `#2E3440` | 细线分隔 |

> **夜间模式作为默认主题的原因**：深色背景能让彩色拼图图片更突出，同时营造"桌面桌游"般的沉浸氛围。主流高品质休闲游戏（如《Alto's Odyssey》《Monument Valley+》《Jigsaw Puzzles by Easybrain》）普遍以深色/低明度为基底。日间模式作为可选主题供用户切换。

#### 2.1.2 品牌色与语义色（严格控制使用范围）

**核心品牌色（Amber Gold 琥珀金）**：`#D4963C` / `#F0B95A`（Hover/高亮）
- 寓意：木质感、桌游感、温暖、高级感。
- **使用范围**：仅用于**主行动按钮（CTA）、成就/星级/金币、重要徽标、选中态描边**。禁止大面积填充。

> 另一份审查建议使用 `#FF9800` 活力暖橙，但该色饱和度过高，在深色背景下会产生刺眼的"霓虹灯效应"。琥珀金 `#D4963C` 保留了温暖的桌游气质，同时对比度更柔和，长时间游玩更舒适。

**功能语义色**：
- 成功/完成：`#3D8B5F` 暗松绿（低饱和，仅用于进度条填充、对勾图标、轻微成功提示，**替代当前高亮绿**）
- 警告/提示：`#E8A339` 暖橙黄（限时活动、复活提示、次要警告）
- 错误/危险：`#D64B4B` 砖红（数据重置、删除、操作失败）
- 信息/辅助：`#5B8DB8` 灰蓝（玩法说明、设置项图标、次要按钮）

**严格禁止**：
- 禁止将任何强调色用于大面积背景填充（如当前绿色 Banner、绿色大按钮）。
- 禁止同屏出现 3 种以上强调色。
- 禁止未解锁关卡使用"纯黑白+灰度"（廉价感），改用"低饱和度+暗角遮罩+模糊"。
- **禁止难度卡片使用多种色彩区分**（如 24块绿、54块蓝、96块橙），这会造成与全局语义色冲突。统一使用中性卡片+琥珀金选中态来区分难度。

### 2.2 字体与排版

| 层级 | 字号范围 | 字重 | 用途 |
|---|---|---|---|
| 页面大标题 | 22-24px | Bold | "主页"、"成就与统计" |
| 模块标题 | 18-20px | SemiBold | "数据统计看板"、"成就勋章墙" |
| 卡片标题 | 16-18px | SemiBold | 关卡名称、活动名称 |
| 正文/描述 | 14-16px | Regular | 描述文字、设置项说明 |
| 数据大字 | 28-36px | Bold | 统计数字、倒计时、星级数字 |
| 标签/角标 | 11-12px | Medium | "#1"、"25 块"、"限时进行中" |

- **数字字体**：统计、计时、碎片数必须使用**粗体等宽或游戏定制字体**（如 DIN、Roboto Mono、Oswald），避免系统默认字体的"办公感"。
- **标题字体**：如有条件，大标题可使用**圆润、稍带手写感**的字体（类似 Nunito、Quicksand 中文圆体），中和拼图游戏的休闲气质。

### 2.3 动效与微交互（全局）

1. **页面转场**：Tab 切换使用**共享元素过渡（Shared Axis）**；页面进栈使用**底部滑入 + 内容延迟淡入（Stagger 80ms）**。
2. **按钮反馈**：所有可点击元素必须带有**按下缩放（Scale 0.96）+ 透明度（0.9）**；主按钮增加**微光扫过（Shimmer）**或**内部光晕扩散**。
3. **卡片交互**：关卡卡片长按弹出**悬浮操作菜单（Context Menu）**；已解锁卡片悬停/触摸时**轻微上浮（Y -4）+ 阴影加深**。
4. **进度与状态**：进度条填充使用**缓动曲线（Ease-Out）**；成就解锁时触发**徽章翻转（Flip）+ 粒子爆裂**；金币领取触发**金币飞向右上角资产栏的粒子飞行动画**。

### 2.4 组件风格统一

- **图标体系**：全局统一使用 **2.5D 面性图标（Filled + 轻微圆角）**，彻底替换当前细线图标。图标视觉重量与文字相当。
- **圆角体系**：
  - 大卡片/弹窗/Sheet：24px
  - 按钮/输入框：16px
  - 标签/角标：8px
  - 禁止混用极端圆角。
- **按钮层级**：
  - 主按钮：琥珀金填充 + 深色文字 + 微阴影
  - 次按钮：透明底 + 琥珀金描边 + 琥珀金文字
  - 文字按钮：仅文字 + 琥珀金
  - 危险按钮：砖红文字/描边，仅在"重置数据"场景使用
- **阴影规范**：日间模式使用微弱弥散阴影（`rgba(30,35,44,0.08)`，Blur 12，Y 4）；夜间模式不使用阴影，改用极细描边（`#2E3440`）或卡片底色与背景色的自然过渡。

### 2.5 弹窗/浮层/Sheet 统一

- 游戏中所有非全屏弹窗统一使用**底部 Sheet**（关卡详情、难度选择、成就领取、确认对话框）。
- 全屏弹窗仅用于：玩法指引（首次进入）、通关结算（Victory Screen）、设置子页。
- Sheet 统一规格：圆角 24px，顶部拖动手柄（6×36px 灰色圆角条），背景遮罩 `rgba(0,0,0,0.6)`。
- **严禁使用 Android 原生黑底 SnackBar** 作为游戏内提示。所有提示统一为顶部 HUD 气泡（深炭褐底 + 微金边 + 图标 + 文字，圆角 24，顶部滑入）。

## 3. 分页面详细审查与改进建议

### 3.1 主页 & 关卡列表

**当前问题**：Banner 简陋、双筛选栏吃掉过多空间、关卡卡片未解锁图黑白生硬、信息角标拥挤。

| 改进项 | 具体方案（遵循统一规范） |
|---|---|
| **今日挑战 Banner** | 改为**全出血大图（今日拼图原图）+ 底部渐变遮罩（黑→透明）**。日期与标题用**暖白粗体**压在遮罩上，右上角加**倒计时徽章**（`⏳ 04:22:10`）和首通奖励 `🪙+50` 徽标。取消当前蓝色背景块。 |
| **筛选栏整合** | 第一行"全部关卡/新手/进阶/大师"改为**深色 Segmented Control（深灰底 + 琥珀金选中态）**，高度压缩至 40px；第二行分类标签改为**可横向滚动的 Chip 栏**，默认显示前 5 个 + "更多"展开按钮。两行整体占用高度不超过 90px。 |
| **关卡卡片** | 卡片统一 24px 圆角。已解锁图保持原图色彩。未解锁图：**降低饱和度至 30% + 叠加 `rgba(26,29,36,0.5)` 暗角遮罩 + 居中放大锁图标（灰蓝色 `#5B8DB8`，半透明）**。彻底淘汰"黑白打印机效果"。 |
| **卡片信息** | "#1"编号移至**左上角小药丸标签（深灰底 + 白字）**；碎片数改为**底部细进度条**（如"已拼 3/25"），节省顶部空间；三星评分放在卡片**底部居中**，使用琥珀金星形。 |
| **通关状态** | **移除正中央大绿勾**！改为在卡片**右下角悬浮 3 颗金色立体星星（⭐⭐⭐）** 或半透明金边角标，不遮挡精美图片核心区域。 |
| **底部导航** | 替换为**面性图标（24px，2px 描边转填充）**。选中态：**琥珀金图标 + 微弱外发光 + 微缩放**，而非单纯变色；非选中态为浅灰。 |

### 3.2 关卡详情弹窗 & 难度选择

**当前问题**：弹窗像配置器，按钮权重不清，难度卡片仅靠数字区分。

| 改进项 | 具体方案 |
|---|---|
| **弹窗形态** | 放弃"居中纯白大弹窗"，改用**底部 Sheet（Bottom Sheet）**，圆角 24px 向上滑出。背景主页内容隐约可见，形成上下文关联。 |
| **难度卡片** | 四个难度不再是纯色方块，而是**带拼图密度示意图的卡片**：卡片上半部分用 4×4/6×6/8×8/10×10 的微型网格示意碎片密度；下半部分显示数字（24/54/96/150）与难度名称。选中态用**琥珀金边框 + 内部微光 + 上浮缩放（Scale 1.05）**。 |
| **切图网格** | 右下角"切图网格"按钮改为**难度卡片上方的 Toggle（开关）**，文案"显示拼图线"，默认开启。 |
| **开始按钮** | 改为**琥珀金大胶囊按钮**，文字根据难度动态变化："轻松开始 →"、"接受挑战 →"、"极限考验 →"。增加内部微光扫过效果。 |
| **继续/重开** | 在关卡详情 Sheet 中，"继续"作为主按钮（琥珀金），"重新开始"降级为**底部文字按钮（灰色）**。恢复提示文案改为情感化表达：**"上次拼到一半啦，继续加油！"** 去掉黄色 Warning 条的心理压力。 |

### 3.3 核心拼图游戏界面（关键战役）

**当前问题**：这是用户停留时间最长的页面，但当前氛围最弱（灰白编织背景、碎片重叠、手指遮挡卡榫、细线图标、无物理质感）。

| 改进项 | 具体方案 |
|---|---|
| **背景桌面** | 默认使用**"深炭灰毛毡"质感**（`#1A1D24` + 微弱布纹贴图）。提供**5 套可解锁桌面主题**（胡桃木、亚麻、星空、大理石、绿绒台布），作为成就奖励或金币解锁内容，既提升沉浸感又提供变现/留存抓手。允许玩家在局内右上角通过画盘图标随时切换。 |
| **拼图区与托盘区** | 取消当前细线硬分割。改为：**底部悬浮 Dock（毛玻璃/半透明黑底）**承载待拼碎片，Dock 高度占屏 25%~30%，圆角 24px 向上包裹。已放置的拼图区在 Dock 上方，形成清晰的"工作区 vs 零件区"物理层次。 |
| **碎片托盘视认性** | **绝对禁止碎片互相叠压**：碎片横向单行等距平铺（或支持双行紧凑平铺），碎片之间留有 8~12px 安全间距，完整露出每一个卡榫和边缘特征。托盘左右两侧加入 **16px 渐隐渐变遮罩（Fade Mask）**，提示玩家可横向滚动。 |
| **托盘分类筛选** | 托盘上方提供微型切换标签：`[ 全部碎片 ]`、`[ 仅边框块 (18) ]`、`[ 仅中心块 (78) ]`。点击"仅边框"时，非边框碎片平滑向右滑出收起，极大幅度降低初学者门槛。 |
| **拖拽微交互** | **防手指遮挡**：当手指按住碎片拖出托盘的一瞬间，碎片应立即产生 **`向上偏移 30px` + `缩放 1.1x` + `投射 8px 弥散下投影`**，确保玩家手指不会挡住碎片底部的卡榫和落点对齐线。 |
| **磁吸正反馈** | 碎片靠近正确位置时，目标空位出现**淡金色轮廓呼吸灯**；拼合瞬间触发：**清脆"咔哒"音效 + Haptic 震动反馈（`mediumImpact`）+ 碎片边缘 0.2s 金色微光闪烁**。这是拼图游戏最核心的"爽点"。 |
| **碎片视觉** | 托盘中的碎片增加**悬浮阴影（Y 2, Blur 6, 黑 20%）**；手指/光标悬停时**放大 1.08x + 阴影加深**；被拖拽的碎片**放大 1.15x + 增加外发光（琥珀金微光）**。 |
| **顶部工具栏** | 细线图标全部替换为**面性图标 + 文字标签**。按钮排列：返回（左）| 提示 💡 | 底图 👁 | 整理 🧩 | 设置 ⚙（右）。图标统一 24px，非激活态灰色，激活态琥珀金。增加**实时计时器**和**已拼计数器**（如"02:15 | 已拼 12/96"）。 |
| **通关瞬间（Victory Screen）** | 必须设计**全屏通关动画**：
  1. 原图从碎片状态无缝拼合完整（1.5s 平滑过渡）；
  2. **礼花/金粉粒子炸裂特效**；
  3. 星级评定以**三颗大金星依次飞入**呈现（伴随清脆"叮！叮！叮！"三连音效）；
  4. 奖励结算：`+30 🪙` 金币翻滚递增动画；
  5. 操作面板：`[ 保存高清壁纸到相册 ]`、`[ 下一关 ]`、`[ 分享战绩 ]`。 |

### 3.4 每日挑战

**当前问题**：仪式感不足，连胜展示简陋，历史翻找笨重。

| 改进项 | 具体方案 |
|---|---|
| **今日卡片** | 采用与"活动页"同等级别的**全出血大图 + 渐变遮罩**设计。"开始挑战"按钮放大至 56px 高，带**脉冲呼吸光环（每 3s 一次）**，暗示"今日首要任务"。 |
| **连胜标识** | "连胜 0 天"改为**火焰徽章图标 + 等宽大数字**。火焰随连胜天数变化：0 天为灰色灰烬，1~2 天为蓝色小火，3~6 天为橙色火焰，7 天以上为金色烈焰 + 粒子特效。 |
| **日历浏览** | 历史挑战由大卡片列表升级为**"月历签到盘（Calendar Grid View）"**：
  - 类似日历小方格，已通关的日期盖上精致的**金色拼图戳印（Golden Stamp）**；
  - 错过的日期显示灰显可补玩（或消耗 10 金币补签）；
  - 当月全勤可解锁"当月专属限定拼图"大宝箱。 |

### 3.5 活动页面

**当前问题**：视觉完成度已相对较高，但图文存在不符，限时紧张感可强化。

| 改进项 | 具体方案 |
|---|---|
| **图文匹配** | 修复"未来赛博都市"配狐狸图等数据与封面语义不符的问题，确保主题包与封面图片严格一致。 |
| **活动卡片** | 全宽出血大图，高度 240px。图片上方叠加**黑→透明渐变遮罩**，确保底部白色标题清晰。标题字号 22px Bold，使用暖白。 |
| **状态标签** | "限时进行中"改为**动态倒计时标签**（深红底 + 白字，带闪烁），直接显示剩余时间如"剩 2天 04:18"；"离线整包"用灰蓝色标签；"在线精选"用琥珀金标签。 |
| **活动进度** | 增加活动收集进度条：例如"未来赛博都市：已收集 3/6 幅作品，集齐解锁【霓虹赛博专属桌面背景】"。 |
| **进入按钮** | 改为**白色半透明毛玻璃按钮（Glassmorphism）+ 琥珀金箭头**，不破坏图片完整性。 |

### 3.6 自制关卡

**当前问题**：功能入口规整但缺乏引导和情感化设计，空状态粗糙，图片被遮挡。

| 改进项 | 具体方案 |
|---|---|

### 3.7 成就与统计

**当前问题**：最容易体现"游戏感"的页面，但目前像数据报表，图标千篇一律。

| 改进项 | 具体方案 |

| **统计 Dashboard** | 放弃 2×3 均分网格。改为**顶部 Hero 区**：
  - 左侧：**弧形环状进度条**展示成就总解锁率（如 `12/25 (48%)`）；
  - 右侧：横向滑动的 4 组精致胶囊数据（总星数 ⭐、通关数 🖼️、已拼碎片 🧩、总时长 ⏱️）；

| **数据字体** | 所有统计数字使用**粗体等宽游戏字体（28-36px）**，单位用 14px 灰色小字跟在数字下方，形成强烈的大小对比。 |
| **成就勋章墙** | 每个成就项是一个横向卡片：

| **进度条语义色** | 进度条不使用统一绿色，而是**铜→银→金**的渐变色（对应普通/稀有/传说成就）。 |
| **解锁提示** | 底部"再获得 2 张 3 星图即可解锁"的 Toast 改为**顶部丝带横幅（Ribbon Banner，琥珀金底 + 深字）**，从顶部滑入，3 秒后自动收起。 |

### 3.8 设置页面

**当前问题**：页面过于原生/工具化，像系统设置而非游戏设置。
