# CHANGES 2026-09-26

## 2026-09-26 16:21 修复拼图触摸与状态同步 4 处缺陷（拖回托盘不落库、抓片首帧误平移、托盘手势双通道、切后台不清理交互态）

- **F1（高）拖回托盘不写回权威状态，碎片会「飞回」棋盘并被锁定（`lib/game/jigsaw_puzzle_game.dart`）**：
  - `handlePieceDragEnd` 步骤 1（放回托盘）原先只改组件 `isInTray` 就 `return`，未同步 `_boardState`；而同函数步骤 2（留在棋盘）会全量写回，两条出路不对称。
  - 后果：该碎片在权威状态里仍保留拖走前的棋盘坐标与 `inTray: false`，`solvedCount` 继续把它算作已就位（进度虚高）；一旦它后来被连通规则判为已植入装配体（如外框补全），`updatePiecesStateAndPriorities` 会置 `isLocked` 并强制瞬移回棋盘槽位 —— 表现为「拖回托盘的碎片凭空飞回棋盘且锁死」。
  - 修复：该分支补写 `copyWith(inTray: true, ny: max(p.ny, 2.0))`，沿用项目既有托盘哨兵约定（与 `organizeTray` / `_applyBoardState` / `exportSnapshotJson` 一致，使 `_isNormalizedOnBoard` 恒为 false）。
  - 触发条件正常玩法可达：碎片处于「坐标已在槽位容差内、但装配体未连通边缘」的孤岛态时拖回托盘，随后补全外框；`hint()` 会提高命中概率。已用探针实证复现修复前后差异。
- **F2（中）放大态下抓取碎片的第一帧误平移棋盘（`lib/game/jigsaw_puzzle_game.dart`、`lib/pages/game_page.dart`）**：
  - 页面 `Listener` 比 Flame 手势识别器更早收到同一个 move 事件（Flutter `dispatchEvent` 按 hit test path 顺序调用，`GestureBinding` 位于路径末尾才 `pointerRouter.route`），故拖拽首个 move 到达时 `onDragStart` 尚未触发，`isDraggingAnyPiece` 仍为 false，被误判为「空白区平移」执行 `panBy(delta)`，放大后每次抓片都会抖一下。
  - 修复：新增 `JigsawPuzzleGame.isPickablePieceAt(canvasPos)`（按下时按命中测试预判定，已锁定/已过滤碎片不算可拾取，保证在已拼区域上拖动仍可平移）；页面新增按指针 id 的 `_pointerStartedOnPiece` 台账，在 `_onPointerDown` 记录、`_onPointerUp`/`_onPointerCancel` 清除，平移分支增加该条件取反。
- **F3（中）托盘碎片方向仲裁期托盘滚动与棋盘平移并存（`lib/pages/game_page.dart`）**：
  - 仲裁期（`_pendingTrayDrag`）既无 `isDragging` 也无 `holdingPiece`，斜向上滑过托盘上沿且 `zoom > 1` 时，Flame 侧 `scrollTray` 与页面侧 `panBy` 同一帧同时生效。
  - 修复：与 F2 共用同一判据，按下点命中可拾取碎片即抑制平移。
- **F4（中）切后台/失焦不清理交互状态（`lib/pages/game_page.dart`）**：
  - 新增幂等入口 `_cancelActivePointerInteraction({bool clearGameInteraction = true})`，统一清理 `cancelHoldingPiece()` / `cancelAllPieceDragging()` / `isPinching` / 指针台账 / `_baseDistance`。
  - 接入 `didChangeAppLifecycleState` 的 `inactive/paused/hidden/detached`（系统可能直接吞掉 pointer up/cancel，页面层与 Flame 层取消回调不成对，残留会让回到前台后的首次点击变成「放下旧碎片」、或把单指手势误判为双指）；`dispose` 仅清理页面侧台账（避免对正在卸载的组件树触发恢复动画）。
- **测试（`test/game_touch_regression_test.dart`，新增）**：4 条回归 —— 拖回托盘后状态写入 `inTray` 与哨兵 `ny`；拖回托盘的碎片在外框补全后不被搬出托盘/不被锁定；拖回托盘后进度不再计为已就位；`isPickablePieceAt` 对「可拾取碎片 / 空白 / 已锁定碎片」三种命中判定。
