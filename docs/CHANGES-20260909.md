# CHANGES-20260909

## [Feature] 推荐难度动态调整：启动计算一次 + 全局缓存

- 新增 `lib/services/recommend_service.dart`：`RecommendRule`（纯规则可单测）+ `RecommendService`（进程级单例）。
  - 默认推荐 **2 档（L2）**，从不推荐 L1/L1.5；最高推荐 **5 档（L5）**，永不推荐 6 档（7 档未启用）；
  - 升档阈值按「该档位**及以上**」的后缀累计完成数判定：L2 及以上累计 5 张 → 推荐 L3；L3 及以上累计 10 张 → 推荐 L4；L4 及以上累计 10 张 → 推荐 L5（熟练用户一开始就选高难关卡，玩 L3+/L4+ 同样计入征服进度，不会因没刷低档被卡在默认档）；
  - 只上推、不下降：取「已征服（达标）的最高档 + 1」，跳档玩家按实力上探；
  - 统计口径全量（main/pack/daily/collection/ugc）`ProgressStore.records` 已完成记录；
  - **只在 app 启动后计算一次**（进程内恒定，期间游玩再多关卡不重算），冷启动刷新。
- `lib/main.dart`：Group1 init 之后、runApp 之前调用 `RecommendService.instance.ensureComputed()`，保证进入 Home 前已算好。
- 消费点全量替换静态 recommended 默认档 → 动态推荐档（历史难度 / 存档续玩优先逻辑保留）：
  - `choose_difficulty_sheet.dart`：初始选中、解码后有效档、选中展示与“推荐”徽章均随全局推荐档（`_preferredTier`/`_isPreferredTier`，含防御回退）；
  - `home_tab_view.dart` / `daily_tab_view.dart` / `pack_levels_page.dart` / `event_levels_page.dart`：默认难度改用 `RecommendService.squareDifficulty`（1:1 假定，面板解码后按实际比例校正到推荐档）；
  - `collection_levels_page.dart` / `my_center_tab_view.dart`：activeDifficultyKey 历史档优先不变，新图 orElse 回退推荐档；
  - `crop_puzzle_page.dart`：自制裁剪默认难度按当前比例直接取推荐档（3 处）。
- 新增 `test/services/recommend_service_test.dart`：23 个用例覆盖阈值边界（4/5/9/10）、封顶 5、L6/L7 不参与、tier key 归类、越界防御与各比例 L2 档精确命中。
