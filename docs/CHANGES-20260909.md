## [Fix] studio 导出四项修复（确认弹窗可读性 / 跨盘 ZIP 移动 / 选中态清理 / 重命名默认值）

## [Fix] clearCache 字节计数归零（上轮 LRU 改造的遗漏）

- `image_cache_manager.dart` `clearCache()`：物理文件已删除但 `_diskCacheBytes` 计数未归零 → 之后每次缓存写入都会触发 `_enforceDiskCacheLimit()` 做一次删不到任何文件的全目录扫描，且因目录为空提前 return、计数永远无法自愈。已修复（清空时同步 `_diskCacheBytes = 0`），测试补断言验证。

## [Docs] 存储分区评估（决定维持现状）+ 设置页行为核查
