# Studio 变更日志 2026-09-10

## [Studio] 回滚/台账 HTTP 接口 + 独立回滚页面 + 回滚原子化（2026-09-10 11:00）

对应审查报告 P1-【5】（回滚无 HTTP 入口）、P0-【3】（回滚非原子）、P2 路径越界；方案见 `docs/rollback-plan-20260910.md`。

### `core/export_rollback.py` — L1.2 原子撤销
- **顺序反转**：由「先账本后镜像」改为「快照 → 回退全部模块 release 镜像 → 全部成功才回滚账本」；任一模块镜像失败即整体失败：从快照还原已回退模块的 index.json、回收站文件移回 release、账本不动，返回 `ok: False` + 失败明细（修复 P0-3 部分失败仍 `ok: True` 的问题）。
- **产物移入回收站而非物理删除**：批次目录 / zip / packs / covers 移入 `.studio/ledger/backups/trashed-{opId}/`（保留原相对结构），成功回滚后可人工找回。
- **路径安全**：新增 `_safe_release_path()`（规范化并限制在 `release/{module}` 内，防 `..` 越界）、`_safe_batch_id()`（batchId 白名单 `[A-Za-z0-9_-]`）；`lstrip("/")` 裸拼接全部替换。
- 返回结构：`deletedFiles` → `trashedFiles`，`error` → `errors[]`；新增 `restoredIndex` / `restoredFiles`（失败还原清单）；`snapshotLedger` 改为文件名（修复 HTTP JSON 序列化失败）。

### `server.py` — 4 个新端点
- `GET /api/ledger/ops?dir=` — 按 opId 聚合的可撤销导出列表（含 legacyCount / totalRecords）。
- `GET /api/ledger/records?dir=&op=` — 单次导出的文件级记录 + supersededIds。
- `GET /api/ledger/audit?dir=&limit=` — rollback 事件流尾部 + 快照备份列表。
- `POST /api/rollback` — `{dir, opId, dryRun|confirm, reason, cleanRelease}`；无 `dryRun`/`confirm` 一律 400；执行注册 `rollback` 类型任务进 `_JOBS`，与进行中的导出/质检互斥（409），防止账本/镜像写入冲突；返回 `undo_op` 结果透传（Path 已转字符串）。
- 路由：`/rollback`、`/rollback.html` 直接服务独立回滚页面。
- `--src` 参数不存在，验证脚本以 `?dir=` 显式传目录。

### `static/` — 独立前端页面（零侵入 index.html）
- 新增 `rollback.html` / `js/rollback-app.js`（独立 Vue 3 应用）/ `css/rollback.css`（复用 studio.css CSS 变量）。
- 功能：操作列表（时间倒序 + 模块/关键字筛选 + legacy 提示）、详情抽屉（文件级明细 + 过滤 + 修订状态）、三步回滚弹窗（dry-run 预览 → 勾选知晓 + 填原因 → 执行）、结果面板（成功摘要 / 失败还原明细 / 快照文件名）、回滚审计 Tab（事件 + 快照备份）。
- 安全：全部文本插值无 `v-html`；`?dir=` 优先于 localStorage 记忆；执行期间按钮 loading + 禁用。

### `test_rollback.py` — 新增 3 用例
- `test_mirror_failure_aborts_entire_rollback`（注入镜像失败 → 整体失败、账本不动、index/批次目录还原、审计记 fail）
- `test_batch_id_whitelist_rejects_traversal`（`../` 越界 batchId 拒绝回退）
- `test_success_returns_trashed_files`（回收站清单 + release 内无批次目录）

### 验证

- 端到端 `temp/` 脚本 15/15 通过（独立 server 子进程 + 临时数据源真实导出后回滚：ops/records/audit 拉取、dry-run、无 confirm 400、confirm 执行、账本清空、源侧批次移入回收站、rollback 事件、审计可见）。

## [Studio] 严重问题修复六项（2026-09-10 09:16）

依据 `studio/docs/studio-full-review-20260910.md` 审查报告，按用户拍板执行 6 项修复（编号对应报告决策清单 1/4/6/10/15/16）。

### 1. 导出并发互斥（`server.py`）
- `/api/export` 入口新增同类任务互斥：已有 running 的导出任务直接 409，避免两个导出同时写 release/index.json 与账本导致 order 撞号、manifest 与产物不符。
- 未携带 `clientTaskId` 的请求补发匿名任务 id（`export_anon_*`），杜绝不传参即可绕过互斥锁。
- 新增 `_job_ensure_finished()` 兜底收口 + `finally` 保护：任何漏网路径都让任务离开 running，防止互斥锁永久生效。
- 质检 worker 增加异常收口包装，避免线程内异常导致任务常驻 running。

### 4. 导出「重新连接」按钮可见性（`static/index.html`）
- reconnect 按钮移出 `.export-result` 容器（原受 `exportLogs.length > 0` 门控）。轮询在收到首条日志前断连时，按钮不再不可见。

### 6. 整体移除旧版 exported.json 支持
- `core/export_tracker.py` 重写为纯权威账本只读视图层：删除 `EXPORTED_FILENAME` / `get_exported_file` / `save_exported_ledger` 与 legacy 回退分支；`record_exports` 只写 `.studio/ledger/exports.json`，写入失败不再静默吞异常。
- `core/exports_ledger.py` 删除 `_try_migrate_legacy()`（旧版自动迁移）。
- `server.py` 移除无调用方的 `/api/exported` 端点。
- **影响**：若某源目录仅有 `exported.json` 而无 `.studio/ledger/exports.json`，其历史已导出记录将不再被识别（首次导出可能重复），上线前需确认在用源目录均已迁移到权威账本。

### 10. 路径解析安全边界（`server.py`）
- `_resolve_image_path` 强制限制在允许根目录内（`?dir=` 优先，其次 `current_root_dir`）；允许根为空时一律拒绝。关闭 `/api/file`、`/api/thumb` 读取本机任意文件的通道。

### 15. 任务类型前缀与互斥粒度
- 约定 clientTaskId 前缀 `quality_` / `export_`（前端由 `qc_`/`exp_` 改为 `quality_`/`export_`）；后端 `_job_kind_of()` 按前缀判定类型，互斥仅作用于同类任务。
- 质检/导出并发拦截文案按真实类型回传；`/api/job/status` 响应新增 `kind` 字段。

### 16. 长边门限注释修正
- 代码真值为 `DEFAULT_LONG_TARGET = 1920`，修正 5 处写作 2160 的过时注释（`base.py` / `crop_compute.py` / `main_exporter.py` / `daily_exporter.py` / `pack_exporter_base.py`）。

## [Studio] main 批次目录自包含（方案 A）+ 导出时间字段统一（增量）

实施文档：`studio/docs/main-batch-dir-selfcontained-and-time-fields-design-20260910.md`。
决策：batch id 保持 `batch_001` 顺序自增；无历史批次（未发布）全量切换；时间字段按增量方案 A（新增 createdAt/updatedAt，addedAt/exportedAt 键名保留）。

### `exporters/main_exporter.py`
- **批次目录自包含**：`main/images/` 平铺改为 `main/batches/{batchId}/`（`index.json` + `images/`）。批次清单 = `batches/{batchId}/index.json`；模块 index entry url = `batches/{batchId}/index.json`；批次内关卡 url 由 `../images/{file}` 改为同目录相对 `images/{file}`（客户端 RFC3986 递归解析，lib/ 零改动）。

### `exporters/daily_exporter.py` / `exporters/pack_exporter_base.py`
- daily month_entry、events/collections item_entry 增加 `createdAt`；**重导同实体（同月/同 pack id）替换 entry 时保留首次 createdAt**，updatedAt 照常更新。

### `core/export_rollback.py`
- `_cleanup_main_release` 由删除 `batches/{batchId}.json` 单文件升级为 **rmtree 整批次目录**（含 images），图片随撤销物理清理（L1 遗留孤儿问题消除）。
