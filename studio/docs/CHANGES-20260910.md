# Studio 变更日志 2026-09-10

## [Studio] main 批次目录自包含（方案 A）+ 导出时间字段统一（增量）

实施文档：`studio/docs/main-batch-dir-selfcontained-and-time-fields-design-20260910.md`。
决策：batch id 保持 `batch_001` 顺序自增；无历史批次（未发布）全量切换；时间字段按增量方案 A（新增 createdAt/updatedAt，addedAt/exportedAt 键名保留）。

### `exporters/main_exporter.py`
- **批次目录自包含**：`main/images/` 平铺改为 `main/batches/{batchId}/`（`index.json` + `images/`）。批次清单 = `batches/{batchId}/index.json`；模块 index entry url = `batches/{batchId}/index.json`；批次内关卡 url 由 `../images/{file}` 改为同目录相对 `images/{file}`（客户端 RFC3986 递归解析，lib/ 零改动）。
- patch 修订文件（`-r{rev}`）落入 patch 批自己的目录 → **随批次生灭**，撤销 = 整目录删除，镜像无孤儿。
- 批次清单顶层与模块 index batch entry 增加 `createdAt`/`updatedAt`（=本次导出时刻，UTC ISO8601）；items 的 `addedAt` 键保留。

### `exporters/daily_exporter.py` / `exporters/pack_exporter_base.py`
- daily month_entry、events/collections item_entry 增加 `createdAt`；**重导同实体（同月/同 pack id）替换 entry 时保留首次 createdAt**，updatedAt 照常更新。

### `core/export_rollback.py`
- `_cleanup_main_release` 由删除 `batches/{batchId}.json` 单文件升级为 **rmtree 整批次目录**（含 images），图片随撤销物理清理（L1 遗留孤儿问题消除）。
