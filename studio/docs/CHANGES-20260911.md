## [Studio] 新增发布前体检工具 `studio/verify_data.py`（2026-09-11 11:15）


  `zipKey`·`zipUrls` 末段与本地文件名一致。
- **输出**：按目录一行一类 `✅ 引用文件 208/208`，末行汇总；`--json` 供 CI；
  **退出码 0 通过 / 1 有问题**。
- **防假绿**：已用 `temp/make_verify_selftest.py` 造的错样本自检（错哈希 / 错大小 / 缺文件 /

## [Studio] Event/Collection 包 ID 自动加模块前缀（2026-09-11 10:10）

### 背景
events / collections 的 zip 会以**扁平文件名**上传到 GitHub Release
（`scripts/deploy/export_data.py` 把 `zipUrl` 改写成 `RELEASE_PREFIX/{文件名}`），
此前包 ID 就是用户填的原文，两类模块的 zip 混在同一个 Release 资产列表里
**完全无法分辨归属**。

### 规则
- `events` → 前缀 `event-`；`collections` → 前缀 `collection-`。
- 前缀进入 `index.json` 的 `id`，`packs/{id}.zip` 与 `covers/{id}.webp` 同基名
  （`out` 侧 `validate_out.py` 本就按 `id` 校验收尾，形态不变）。
- 只有新导出受影响；历史条目保持原 id 不动（不做迁移）。
- **注意**：历史无前缀条目与新带前缀条目不会互相判重。例如旧条目 `halloween2026`
  存在时，再填 `halloween2026` 会生成 `event-halloween2026` 并通过唯一性预检
  （两者 id 不同，不构成客户端数据错乱；同批图片仍受账本去重保护）。

### 代码
- **`exporters/base.py`**：新增 `PACK_ID_PREFIXES` / `pack_id_prefix()` /
  `normalize_pack_id(module, raw)`——去空白 + 幂等补前缀（粘贴 `event-xxx`
  或大小写差异都不会叠加成 `event-event-xxx`；只有前缀无正文返回空串）。
- **`exporters/pack_exporter_base.py`**：`validate()` 与 `execute()` 统一走
  `normalize_pack_id`，包 ID 在此一处出炉，id / zip / cover / 账本 `packId` /
  `logicalId` / 审计 `export_meta` 全部同源带前缀。
- **`server.py`**：`/api/export/check-pack-id` 预检同样规范化（否则预检 id 与
  实际写入的 id 不一致会漏判）。响应回显规范化后的 id。
- **前端**：导出面板第①步「活动/合集 ID」改为**固定前缀标签 + 只填后半段**
  （`v-model` 换成 `:value + @input`，粘贴整串时剥掉前缀并回写 DOM）；
  必填校验、唯一性预检、导出 payload 一律送带前缀的最终 ID；
  第③步新增「包 ID / ZIP / 封面」确认条。新增样式 `.pack-id-input`。

### 测试
- 新增 `TestPackIdPrefix`（4 项）：补前缀、幂等（含大小写/重复前缀）、
  空值（只有前缀视为缺 ID）、无前缀模块 main/daily 不受影响。
- `test_event_exporter` / `test_collection_exporter` 断言改为带前缀的
  zip 基名与 `zipUrl`；`test_pack_exporter_rejects_duplicate_id` 同步。
- `test_server_check_pack_id_api` 扩为验证「只填后半段也能命中」「粘贴整串幂等命中」
  「event / collection 前缀互不串味」。
- 全量：`test_studio` 56 项、`test_rollback/test_ledger/test_frontend/test_git_guard/
  test_log_routing/test_workspace/test_image_proc` 82 项，全绿。

### 文档
- `docs/unified-content-export-and-storage-architecture.md`：示例文件名/id 更新为带前缀；
  并顺手修正两处长期漂移——示例里的 `eventId` / `collectionId` 字段实际不会写入
