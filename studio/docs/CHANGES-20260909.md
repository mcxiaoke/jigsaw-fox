# Studio 变更日志 2026-09-09

## [Studio] 品质过滤改为复选框 + 排序方向切换 + tagCounts 联动过滤

- **品质过滤**：删除原品质下拉框 + 分数 min/max 输入框 + 5 个快捷按钮，替换为 6 个品质复选框（S/A/B/C/F/未质检），各带数量标签。全不选 = 全部展示，选一个或多个 = 仅显示对应品质。数量来自服务端 `qualitySummary` 全量统计，不受复选框自身过滤影响。
- **排序方向**：排序下拉旁新增 ↑↓ 方向切换按钮，`sortOrder` 默认值从 `"asc"` 改为 `"desc"`（得分排序默认高→低）。按钮 title 同步更新。
- **tagCounts 联动过滤**：`tagCounts` computed 数据源从 `records.value`（全量）改为 `filteredRecords`（过滤后），左侧侧边栏各 tag 的计数会随品质复选框、搜索、隐藏已导出等过滤实时联动。伪分类（已导出、不合格、重复）计数仍基于全量 `records.value`，本次未改动。
- 涉及文件：`studio/static/index.html`、`studio/static/js/app.js`。后端 `server.py` 无改动。

## content box 算法：sal90 落地 + fusion（std25∪sal90）融合默认
- `studio/core/crop_compute.py`：新增 `saliency_content_box`（显著性能量 q=90 掩膜跨度 + pad，空掩膜/均质自动回退整图），并将 `fusion_content_box` 设为默认——同图分别算 sal90 与 std25（细节纹理），两框相交时逐边取并集（任一算法保留的边不丢弃），不相交时回退取面积较大者；docstring 含算法语义与实测依据。
- `studio/core/quality_evaluator.py` / `studio/core/image_proc.py`：质检 `_compute_smart_crop` 与导出 `trim_background` 的 content_box 由 usm 细节阈值法 → sal90 → `fusion_content_box`，两条链路口径统一。
- 验证：71 张 Animals 样库 fusion 与手工并集逐字节一致 71/71，34 张有并集增益（典型 fox 顶部 738→524）；py_compile 通过。
- 注意：质检详情走 hash 缓存，需清空质量缓存/重新质检才刷新 viewer 框，导出链路实时生效。

## Viewer 绿框（content_box）叠加显示与不渲染修复
- `studio/static/{js/app.js,index.html,css/studio.css}`：viewer 叠加绿色实线 content_box 框 + 框内左上角标签；修复绿框完全不渲染的根因——`contentOverlayStyle` computed 未从 setup return 导出，模板绑定 undefined 渲染为 4×4px 空盒；标签移入框内、z-index 提升到 crop 框之上、贴边加内圈辅助线保证可辨识。
- 验证：node --check + 启动 server 浏览器实测，绿框内联样式与 rect 正确贴合图片边缘，红框不受影响。

## quality_visualize 工具链
- `scripts/quality_visualize.py`：新增 `--cbox-algs` 对比模式（usm12/std25/sal90/fusion 多色实线框 + 算法名小标签；显式传入才启用，启用时仅输出 `_cbox.jpg` 跳过 `_qc`）；`--compare` 5 档预设不受影响。
